# UTA · Windows 日语歌学习程序

UTA 是 Windows 10 / 11 x64 桌面程序，用歌曲歌词练习日语读音、词汇和句意。本分支只维护 Windows EXE，当前版本为 **1.3.0**。

## 下载与启动

从 [GitHub Windows 1.3.0 Release](https://github.com/meilawiet/Japanese-song-learning-website/releases/tag/windows-v1.3.0) 下载 **`UTA-1.3.0-Windows-x64.zip`**，完整解压 `UTA-Windows-x64` 文件夹，再双击其中的 `UTA.exe`。也可从 [Gitee 成品镜像](https://gitee.com/mzh18392597195/uta-windows/releases/tag/windows-v1.3.0) 下载；超过附件上限的文件提供分片和合并校验工具，合并后与 GitHub 原文件完全一致。

程序包含 Electron、Python 注音服务、Sudachi 和 Tomoshi 词典，无需另装 Node.js、Python 或其他运行环境。请保留完整程序文件夹，仅复制 EXE 无法运行。建议解压到当前用户可写的目录。

## 从旧版升级，保留学习数据

本次提供完整 ZIP 和三个直接升级到 1.3.0 的增量包，均附 SHA-256 校验文件：

| 当前 Windows 版本 | 对应增量包 |
| --- | --- |
| 1.2.0 | `UTA-1.2.0-to-1.3.0-Windows-x64.utapatch` |
| 1.2.1（此前提供的本地测试版） | `UTA-1.2.1-to-1.3.0-Windows-x64.utapatch` |
| 1.2.2 | `UTA-1.2.2-to-1.3.0-Windows-x64.utapatch` |

在旧版“检查更新”中在线下载，或将对应 `.utapatch` 拖入主窗口，校验后确认退出、安装并重新打开。**可从上述版本直接升级，无需依次安装中间版本。** 新版入口为“设置 → 关于 → 检查更新”。1.2.1 增量包针对此前实际提供的测试包，任意自行构建的同版本可能不兼容；文件与基线不符时，在线更新可回退完整包。

1.1.28 及以前发布的版本没有增量更新器，需手动升级：

1. 退出旧版 UTA，备份旧 `UTA.exe` 旁的 **`uta-data`** 文件夹。
2. 将 1.3.0 完整 ZIP 解压到新目录。
3. 把旧的 `uta-data` 文件夹复制到新版 `UTA.exe` 同级，再运行新版并核对歌曲和学习记录。

发布 ZIP 不含用户数据。`uta-data` 保存歌曲、音频、学习记录、注音校正、歌词源设置和加密凭据；跨电脑或 Windows 用户复制时，API Key 需要重新填写。

## 1.3.0 更新重点

- **单句循环与起止时间**：慢放旁增加循环次数，支持 1、2、3、5、10 次、自定义 1–99 次和无限循环。右键编辑歌词可独立输入开始、结束时间，并用 ±0.2 秒微调；结束时间留空时按下一句或音频结尾截断，单句仍保留 0.5 秒提前量。
- **已导入歌词重新归类**：歌曲库 → 编辑歌曲信息 → 重新归类与配对，可将已保存内容调整为原文、译文、罗马音或忽略，并手动指定辅助轨对应的原文。先预览并应用到草稿，再保存；原文未变且身份可对应的句子保留学习记录，支持撤销。
- **选词与分栏**：双击歌词播放不再留下词语高亮；点词才选中并展开右栏，点空白取消选词并收起自动展开的右栏。顶栏可控制两侧边栏，保留调整后的宽度；手动展开的右栏保持展开。
- **继续上次学习**：启动时恢复上次正在学习的歌曲，保持暂停；歌曲已删除时回退到可用歌曲。
- **WebDAV 跨端互通入口**：设置新增手动上传快照、预览恢复和按歌曲补下载音频。音频按大小与 SHA-256 去重复用，恢复前保存本机恢复点，失败或中断可恢复。恢复会替换整份本机资料，尚无自动双向合并或选择性合并学习记录。
- **标注与备份兼容**：保留协议中的来源/人工标注、空读音与按歌显示设置；旧本地备份继续可读，纯歌词、待下载音频与空时间资料使用新版备份格式。

跨端功能要求另一端支持相同数据协议；本次完成 Windows 隔离 EXE 和本机模拟 WebDAV 验证，**真实公网 WebDAV 与安卓真机往返尚未验收**，不能保证任意已有 APK 都兼容。详见 [跨端互通说明](docs/CROSS_PLATFORM.md)。

完整更新公告见 [Windows 1.3.0 更新公告](docs/releases/windows-v1.3.0.md)。

## 主要功能

- **导入与编辑**：单首或批量导入音频和 LRC，本地歌词优先配对，缺少时可联网搜索。选用后预览原文、译文、罗马音和时间戳，再确认导入；支持改轨道、插句、编辑歌词与自定义分词。歌词自带的假名优先于自动注音。已导入歌曲也可搜索替换歌词、重新归类和手动配对三条轨道，批量导入可逐首选择封面。
- **发音学习**：本地分词、假名注音和日中词义查询；可修正读音、隐藏某个词的注音，分别调节歌词、假名、罗马音和翻译字号；单句循环及开始/结束时间可单独调整。
- **跟唱与选段练习**：任一句开始连续播放，可自定义背景、切换注音与译文、跟随当前歌词。Ctrl 选择连续句子后可慢放，设定 3 次、5 次或无限循环、1–3 秒跟读间隔，以及“听一次 → 自己读 → 再听一次”。选段使用准确时间戳，单句保留原有播放提前量。
- **AI 辅助**：按需解析歌词、复核读音及词典分词；建议可采纳、跳过或恢复。配置服务后可测试连接、保存设置。批量 AI 解析由用户明确勾选。
- **Windows 操作**：歌词右键菜单、播放及选句快捷键，可调整并记住宽度、主动收放的分栏，启动恢复上次学习歌曲，未保存修改退出提示；任务面板显示导入、注音和 AI 解析的进度、失败原因、重试与取消。
- **数据管理**：收藏、掌握与复习记录；导出和恢复 `.uta-backup`，恢复前预览并自动保存学习快照。API Key 可仅用于当前会话，或使用 Windows 加密记住，不进入普通学习备份。WebDAV 云快照默认不包含 Key；主动勾选上传 Key 时需再次确认。

本地播放、注音、词义和已有记录可离线使用。在线歌词、封面和 AI 的可用性取决于网络及对应服务，AI 调用可能收费。某个平台或歌曲版本未提供的翻译／注音不会被伪造。跨端互通需要双方协议兼容；此版本提供手动快照上传和替换恢复，不提供自动双向合并。

## 常用操作与后续更新

发音学习页单击选句、双击播放，Ctrl 点击首末句选择连续范围，右键歌词打开编辑菜单。跟唱模式点击任意一句即可从该句连续播放。设置分为常规设置、主题设置、数据管理、AI 服务、歌词源、跨端互通和关于；主题中管理字体与注音，关于中检查更新。

检查更新由用户主动发起，在“设置 → 关于 → 检查更新”在线下载适配本机的直达增量包；没有适配包时使用完整包，无需逐个安装中间版本。也可下载对应 `.utapatch` 后拖入程序，Gitee 分片需先合并。只有确认“退出 UTA、安装并重新打开”才会切换版本；存在未保存编辑时会先提示。更新不替换 `uta-data`，并保留旧程序版本用于恢复。完整 ZIP 仍可用于首次安装或手动升级。

此前使用过版本号同为 1.3.0 的本地测试版时，同版本不会触发在线升级；请使用正式完整 ZIP 按上述手动迁移方式更新，保留 `uta-data`。

详细操作与快捷键见 [Windows 使用说明](docs/WINDOWS.md)。启动失败时查看 `uta-data/logs/desktop.log`。程序尚未购买代码签名证书，Windows 可能提示未知发布者。

## 从源码构建

```powershell
git clone --branch Windows-exe https://github.com/meilawiet/Japanese-song-learning-website.git E:\project\UTA-exe
cd E:\project\UTA-exe
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\windows.ps1 setup
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\windows.ps1 test
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\windows.ps1 build
```

也可运行 `安装 Windows 开发环境.cmd`、`构建 Windows 程序.cmd`。便携程序位于 `release/UTA-Windows-x64/`，完整 ZIP 与校验文件位于 `release/`。`npm run windows:release` 默认相对最近一个公开 Windows 完整包生成增量；多个起始版本分别使用经过校验的实际程序基线执行 `node scripts/create-windows-patch.mjs <旧版便携目录> <新版便携目录> <输出目录>`。Gitee 仅分发成品，不同步源码。

源码入口是 `desktop/`、`src/` 和 `server/`，构建脚本在 `scripts/`。依赖、缓存、临时文件和产物保存在项目目录；用户歌曲、学习资料、凭据及下载的词典数据库不提交 Git。
