# UTA · 日语歌曲学习

用自己的歌曲练习日语：逐句听、看注音、慢速练习，再跟着原唱连续唱。支持安卓应用与电脑网页。

安卓应用与网页均可使用；安卓开发维护在 `android-dev` 分支。

### 安卓 1.3.1 更新

- 假名显示统一只标汉字段：先沿用来源/人工/字典的最终读音，再按原文假名定位汉字读音；例如“伝え”仅在“伝”上显示“つた”。只改变显示，保留完整来源读音、校正与整词罗马音，已有缓存同样生效。
- 更新提示可勾选“此版本不再提示更新”后取消，仅跳过这个待更新版本的启动提示；手动检查和后续新版本仍可提示。
- 安卓新导入或重新注音时，先识别完整词的读音，再以假名锚点拆分汉字/假名片段，例如“抱｜きしめ”；读音对应不唯一时保持整体，不改已有人工词界和校正。
- UtaTen 导入按站点日文短语之间的空格分句，同时保留假名和罗马音；不拆英文词间空格，不修改网易云等其他来源的句子及时间轴。已保存歌曲不自动重排，可重新导入使用新规则。
- 酷我搜索补齐网页使用的参数，修复部分歌曲原唱与其他版本搜索结果缺失的问题。

### 安卓 1.3.0 更新

- 学习页使用紧凑的歌词分行列表，右侧以图标操作掌握状态及整句解析；页头与歌词共同滚动，恢复原封面尺寸和整行学习进度，并以留白、细线分隔。修复日式引号和顿号导致来源罗马音无法对齐，以及底部提示溢出的问题。
- 安卓将逐句学习与连续跟唱合并到同一学习页：底部居中播放键、进度条、模式及倍速选择、问 AI 与更多菜单；连续模式自动跟随当前歌词，逐句模式播完选中句停下。展开解析暂停，需手动继续；系统返回退出学习页。
- 更多菜单支持不注音、平假名、罗马音、双注音，以及独立显示翻译开关。仅有带完整时间戳的歌词时支持静音计时跟唱、暂停、拖动和倍速；无音频时以最后一句时间戳为计时终点，无时间戳仍可阅读和编辑。
- 安卓导入页与歌曲编辑中的歌词搜索支持粘贴网易云、QQ 音乐、酷狗、酷我的单曲分享链接或整段分享文案，自动识别歌名、歌手并使用当前配置的歌词来源搜索；兼容常见电脑、手机详情页和受支持的短链接跳转。不下载平台音频、不自动添加平台歌词源；失效、登录受限、歌单及未支持的链接会提示手动输入歌名，不能保证所有链接永久有效。
- 支持只导入歌词、稍后在歌曲编辑中补音频；歌词文本不按扩展名限制，LRC、TXT 和 UTA 注音 JSON 均可读取。无时间戳可以先阅读，补音频时会提示手动填写时间戳或重新上传带时间戳的歌词；时间轴未完整前不启用逐句试听和跟唱。
- 歌词搜索支持混合搜索或指定来源，优先展示已确认含注音的结果；新增 UtaTen 默认来源及网站假名/罗马音导入，无时间轴的结果也可选用。网易云、酷我、酷狗和 QQ 音乐网址仍需自行配置；QQ 音乐目前仍为网页入口。
- 纯歌词可以备份、恢复及按首云下载；本地备份含无音频或无时间轴资料时使用 v2，旧版本应用不能读取。已有传统歌曲 v1 备份继续兼容。
- 修复 UtaTen 括号假名在整句罗马音无法唯一切分时被清空的问题：用有效括号注音辅助定位，整句匹配失败仍保留明确注音；兼容汉字与括号间的空格。已导入歌词可直接恢复显示，无需重新导入。

### 安卓 1.2.0 更新

- 歌词编辑支持整句点选词界：每个字符之间显示可点击的 `|`，高亮处分词，淡色处合并，确认后只保留选中的分隔符；例如 `わかれ道` → `わかれ｜道`，并校对各段读音。
- 读音模式按词组排列假名、罗马音和原文；包含汉字的完整词组显示假名，换行时三层一起移动。歌词卡片缩小留白，高度随内容变化。
- AI 先复核分词，再复核读音，可以质疑人工改音或主动留空；只有用户采用后才修改，支持全选、取消全选和跳过。
- 复核结果按句子显示原歌词与试听入口；本机保存各次历史、建议和采纳情况，未采纳或跳过的建议可以重新选择，也可删除记录。当前历史不包含在云备份中。
- 当前版本实际使用的提示词见 [AI复核歌词提示词](docs/AI复核歌词提示词-1.2.0.md)。
- 歌词编辑、AI 复核等弹窗独立滚动，关闭后恢复背景页面原位置；AI 复核四个操作按钮位于结果末尾，随内容滚动。
- WebDAV 新备份将歌曲附件与目录分离：先恢复歌曲资料、封面及学习进度，未下载歌曲显示暗色封面，点开确认后只下载该首音频和歌词。相同歌曲附件复用；已下载且附件未变化的歌曲在再次恢复目录时保留本机音频。
- 上传显示文件准备、网络发送速度与服务器确认阶段，记录实际传输量和耗时。新目录备份为 v2；旧完整备份可继续恢复，但仍需整包下载。要使用按首下载，先用此版本上传一份新目录备份。旧版本应用不能读取 v2 目录。

## 安卓端下载与安装

### 1. 下载 APK

**[前往 Releases 下载安卓 APK](https://github.com/meilawiet/Japanese-song-learning-website/releases)**

打开版本页面，展开 **Assets（附件）**，下载以 **.apk** 结尾的安装包。

> 安卓用户选择 APK 安装包。Source code 是项目源码，用于网页运行或开发。

### 2. 安装到手机

1. 在手机上打开下载好的 APK 文件。
2. 如果系统提示需要授权，为用于打开 APK 的浏览器或文件管理器开启“允许安装此来源的应用”。
3. 按系统提示安装，完成后打开 **UTA**。

支持 Android 7.0 及以上；目前已在 Android 13 手机测试。正常安装和使用无需开启 USB 调试，无需电脑。

可覆盖安装同签名的旧版，保留本机数据。更新内容请查看 Releases 页面。

## 第一次使用

### 1. 导入一首歌

进入 **我的 → 歌曲库 → 导入 → 从手机文件导入**：

1. 可选歌曲音频，如 MP3、M4A、WAV 或 OGG；也可先只导入歌词。选择音频后会按标签或文件名尝试识别歌名、歌手并搜索歌词。
2. 选择自己的歌词文本（LRC、TXT、UTA 注音 JSON 等），或搜索并选用歌词；也可粘贴受支持平台的歌曲分享链接识别歌名。无时间戳也能导入阅读，之后可在歌曲编辑中补音频及时间戳。
3. 核对歌名、歌手、歌词和时间轴，选择封面。
4. 选择 **直接导入**，或 **导入并在后台生成 AI 解析**，确认保存。

直接导入后即可学习，之后可在学习页补充 AI 解析。后台生成需要先配置 AI 服务，生成期间可继续操作；应用关闭后，未完成任务会在下次打开时续做。

歌词搜索结果可能存在同名歌曲或版本差异，请先核对。其他音乐网站提供搜索入口，下载的文件需由你自行选择导入。UTA 不附带商业歌曲，也不提供所有网站音频的一键下载。

**AI复核歌词**：逐句学习 → 更多 → AI复核歌词，结合整曲上下文与自带罗马音，先检查分词，再检查读音遗漏及异常。结果按句显示原歌词、试听和建议；可以全选、逐条采用或跳过，也可选中待核对问题，请 AI 生成具体调整。AI 可以提出拆分或合并词组建议（如一人整体读ひとり），也可质疑人工改音或主动留空，必须由用户确认采用后才修改。特殊唱法缺少录音依据时作为候选显示，需试听确认；无误条目不展示，未解决问题以红字提示，未补齐的汉字读音保留待处理项。复核历史保存在本机，记录采纳和跳过情况，未采纳建议可重新选择，记录可删除；历史不进入云备份。疑似缺字、来源不匹配等只给待核对提示，不直接改写原文或时间轴。英文默认保留。使用设置中的AI服务，可能产生调用费用。

**安卓 1.1.0 新增**：设置 → 数据管理分为“WebDAV云备份”和“歌曲与歌词来源”。来源支持添加、编辑、删除；默认配置 LRCLIB 与原有网页入口，网易云音乐、酷狗音乐、酷我音乐不预配置，需要用户主动添加相应网址后才启用已适配的应用内歌词搜索。普通网址只提供浏览器入口，搜索模板可使用 `{query}`，填写任意网址不等于支持自动解析该网站。网易云会尝试获取原歌词、翻译和平台整句罗马音；酷狗和酷我当前导入接口实际返回的逐句歌词。辅助轨不一定存在，时间戳无法与原文匹配的行会提示并跳过，选用后仍需核对导入预览。自带罗马音在可靠对齐后用于汉字注音与整句读音，人工校正仍保持最高优先级；缺少自带注音时沿用本地自动生成。QQ 音乐暂未接通。新增平台来源仅用于安卓端，网页仍使用原有 LRCLIB 搜索。用户自行配置不等于取得平台或内容授权，接口也可能变化或停止提供数据。

安卓 1.1.0 还新增跟唱当前句自动居中、设置的五项纵向目录，以及主题设置。主题设置支持歌词字号（80%–160%）、应用字号（80%–130%），提供“白羽翠风”、“星杖靛蓝”、“绯剑赤霞”、“旅途麦金”四套浅色配色，即时生效并保存在本机；两个字号设置会叠加。联网歌词的选用按钮放在结果左侧，长名称自动换行。

安卓 1.1.0 识别汉字后的括号假名（例如“囚（とら）”），学习显示时提取为注音，原始歌词仍保留。读音优先使用人工校正（包括主动留空），然后使用歌词自带罗马音；没有罗马音时可使用括号假名，最后才使用本地词典。可可靠对齐的罗马音用于汉字上方与整句读音；连续汉字缺乏词边界时可整组注音，无法可靠对齐时保留整句来源读音，不强行分配到汉字。逐句学习、跟唱、单句编辑与问 AI 上下文共用这些规则。

安卓复习入口暂时显示“复习功能尚未完善，请等待后续版本发布”；设置子页使用系统返回手势或返回按钮逐层返回，不再显示“←设置”。

### 2. 开始学习

底部有三个入口：

| 入口 | 用法 |
| --- | --- |
| 学习 | 进入统一学习页，在底部切换逐句学习或连续跟唱 |
| 复习 | 显示功能开发进度提示，当前尚未开放 |
| 我的 | 打开歌曲库或设置，查看个人头像与昵称 |

**逐句学习**

- 点击整句歌词区域播放；再点暂停；暂停后再点，从这一句开头重播。
- 底部播放器可暂停、拖动进度和切换倍速，支持 1×、0.75×、0.5×、0.25×。播放按钮保持屏幕居中。
- 底部“更多”位于“问 AI”右侧，可选择不注音、平假名、罗马音、双注音，独立开关翻译，并进入 AI 复核或整曲解析。
- 长按歌词，点击“编辑”，可调整这一句歌词、重新注音或人工修正读音；“编辑分词”可以点选字符间的竖线，确认自己需要的词界。
- 校对读音可以留空，留空的词不显示注音。每个词可选择“日语罗马音转假名”或“按原样保留”，避免英语等被误转换；逐句与跟唱共用保存的校对结果。
- “编辑这一句”会带入 LRC 自带翻译，支持修改或留空保存。
- 导入预览与歌曲编辑都可选择在第1句之前、任意句之后或末尾添加歌词。
- 导入预览和歌曲编辑支持逐句输入罗马音；LRC 自带的同时间戳罗马音会自动填入。可可靠对齐的来源罗马音用于词级读音，优先级为人工校正、歌词自带注音、本地自动注音；英文默认原样保留。读音模式按完整词组排列假名、罗马音和原文，假名仅标含汉字的词组，换行时整组移动；来源尚未按词对齐时会另行显示完整来源罗马音。
- 点击歌曲封面选歌；歌词右侧圆圈／勾用于掌握状态，星光图标用于解析。展开解析自动暂停，需手动继续播放。句号在左上角，歌词左对齐。
- 点击右下角“问 AI”，询问词义、语法和歌词含义；可新建、继续或删除历史对话。

**连续跟唱**

- 底部模式按钮选择“连续跟唱”，点击播放从当前进度继续，自动播放后续句并滚动歌词；首次进入从零秒开始。
- 选择“逐句学习”后播完选中句停下。点击歌词从该句开始播放，再点当前播放句暂停；底部播放键可暂停和继续。
- 只导入带完整时间戳的歌词时也能静音跟唱，支持暂停、拖动与倍速，以最后一句时间戳为终点。无时间戳时保留阅读与编辑，补全后可播放跟随。
- 两种模式共用翻译开关、注音和人工校正；学习页隐藏底部导航，返回退出后恢复。

返回手势或系统返回键会先关闭弹窗，再返回上一级；在学习、复习、我的三个主界面，首次返回提示“再次返回后退出”。

## 管理歌曲与封面

进入 **我的 → 歌曲库**，右上角可切换封面网格或歌名列表，支持按歌名、歌手搜索。

- 网格模式：长按封面打开操作菜单。
- 列表模式：点击歌曲右侧的三点按钮打开菜单。
- 菜单支持删除和编辑歌曲信息；编辑内分为歌曲名称、歌手名称、歌曲封面、重新上传歌曲或歌词、歌词与时间轴五个可展开分区。新增歌词可选插入位置，重新上传支持联网查找歌词及打开歌曲下载网站。网站入口包括下歌吧、歌曲宝、Toomic / MusicEnc、爱歌词网和世纪音乐网。

封面可从 Apple Music、网易云音乐、QQ 音乐、酷狗音乐的搜索结果中选择，也可上传图片或使用默认封面。选用的联网封面会保存到本机，断网后仍可显示。

## 设置

进入 **我的 → 设置**，包含个人资料、数据管理、AI 服务、主题设置、关于五项纵向入口。

### 个人资料

可修改昵称、上传并裁剪头像。支持 JPG、PNG、WebP、GIF，每个文件不超过 **10 MB**，图片不超过 **4000 万像素**；GIF 保留动画。

头像和昵称保存在本机。我的页面点击头像可放大查看，修改请进入设置。

### AI 服务

1. 在 **AI 服务** 中选 DeepSeek，或填写兼容服务的 API 地址、API Key 和模型名称。
2. 点击 **测试连接**，成功后点击 **保存设置**。
3. 返回学习页使用整曲解析、逐句解析或“问 AI”。

自动注音可离线使用，不需要 AI Key。AI 功能需要连接你配置的服务，测试连接和解析可能产生调用费用。

“启用联网查询”默认关闭，目前支持 DeepSeek 官方接口，也可在“问 AI”对话中切换。联网查询可能增加费用，其他供应商的联网功能尚未适配。

API Key 默认仅用于本次应用会话；选择“在这部手机上记住 API Key”后，由手机系统加密保存。

### 数据管理：WebDAV 云备份

填写支持 WebDAV 的服务提供方给出的 **HTTPS 目录地址、账号和应用密码**，测试连接后保存配置。

- **上传本机数据**：备份歌曲与音频、封面、歌词、学习进度、个人资料、对话和 AI 配置，每次上传保留新目录。歌曲附件与目录分离，未修改的歌曲附件可复用，上传显示准备、实际网络发送速度与服务器确认阶段。
- **查看云端备份**：选择备份，下载并预览，确认后恢复。新备份先恢复封面、歌曲资料和学习进度；未下载歌曲封面变暗，点击确认后只下载该首音频与歌词，下载完成恢复正常封面。已在本机下载且附件未变的歌曲可以保留。恢复会替换本机数据，操作前建议先备份当前数据。
- **格式兼容**：旧完整备份仍可恢复，但需要整包下载。要使用按首下载，先用 1.2.0 上传一份新备份；旧版本应用不能读取新的 v2 云目录。删除云端歌曲附件会使引用它的目录无法下载该歌曲。
- 默认上传全部数据但 **不含 API Key**；选择包含 Key 时会警告并要求确认。不要轻易上传密钥，拥有备份的人可能读取并使用它。WebDAV 密码不进入备份。

## 常见问题

**断网可以使用吗？**

已导入的歌曲、已保存的封面、离线注音和学习进度可继续使用。歌词/封面搜索、AI、云备份和更新检查需要网络。

**为什么搜不到歌词或封面？**

尝试修改歌名或歌手，也可自行导入 LRC、上传封面。平台资源与接口可能限制搜索，搜索失败不影响本地导入。

**网易云下载的 NCM 能直接导入吗？**

目前不支持 NCM 等加密音频文件，请准备可正常播放的标准音频文件。

**卸载或清除应用数据会怎样？**

会丢失保存在应用内的歌曲和学习资料，请先完成云备份。更新通常可覆盖安装；若提示签名不一致，请先保留备份，不要直接卸载后重试。

**是否必须连接电脑？**

手机文件导入和日常学习可独立完成。如果使用“从电脑网页导入”，电脑端操作另见 [电脑传歌与开发说明](docs/PROJECT_SETUP_ARCHIVE.md#从电脑网页把已有歌曲导入手机)；其中 USB 传歌需要 USB 调试。Wi-Fi 传歌建议电脑连接手机热点，查找电脑成功率更高。

## 数据与隐私

歌曲、学习进度、头像和对话默认保存在本机。自动注音在手机离线完成；AI 会向你选择的服务发送相关歌词上下文，不发送音频；封面和歌词搜索会发送搜索关键词；启用 WebDAV 备份后会将选择的数据发送到你的云服务。

请使用有权使用的音频、歌词和图片，妥善保管备份与密钥。

### 网页端功能

- 导入带时间轴的日语 LRC 与歌曲音频；保存前可预览并校对歌词、译文、时间戳和封面。
- 根据每句时间戳播放原声，播放起点提前 0.5 秒；支持 `1× / 0.75× / 0.5× / 0.25×` 慢放。手机上点击整句歌词区域即可播放，再点暂停，暂停后再点从句首重播；掌握状态和解析按钮仍各自独立。
- 如果 LRC 含中文译文，会在对应日文歌词下显示；每句可切换“已掌握 / 未掌握”，歌曲库同步显示掌握进度。
- 逐句练习模式先隐藏读音和译文，听原声、自行回忆后再揭晓；选“还要再练”的句子自动进入复习清单。
- 用 SudachiPy 生成逐词假名读音；可手动校正，修正结果优先显示。
- 提供原文、注音（平假名或罗马音）、遮住读音三种学习模式。
- 设置中可切换平假名或罗马音注音，即时替换读音展示；偏好保存在本地并随学习备份迁移。
- 本地日中词典提供常用中文释义和词形信息；纯假名同形词会按词性优先消歧。
- 鼠标拖选歌词片段后可请求 AI 语境讲解；AI 只给建议，不会自动修改学习内容。
- 网页导入歌曲时可选择保存后后台生成每句的 AI 解析；歌词下方可立即查看整句意思、关键表达与语法，选中片段的单独讲解仍可使用。
- AI 复核整首歌曲中可能不合理的读音，并逐条供用户确认。
- 学习进度、读音修正、手工词义和网页导入歌曲都保存于浏览器本地。
- 可从“设置 → 数据管理”导出单个本地备份文件，并在另一浏览器恢复歌曲、音频、读音修正与学习进度。
- “设置 → AI 服务”支持服务端默认配置或自定义 Chat Completions 兼容服务，并可测试连接；密钥不进入学习备份。
- 内置日漫抒情风格主页和独立歌曲库；可按歌名或歌手检索、切换歌曲，并删除网页导入的歌曲。
- 导入或更换封面时可在 Apple Music、网易云音乐、QQ 音乐、酷狗音乐的候选中选择，也可上传本地图片、填写图片链接或使用默认封面；网页和 Android 均可使用。

## 逐句练习与复习

在“发音学习”页面点击“开始逐句练习”。练习卡片先只显示日文原句；可以播放该句原声并调整速度，尝试自己读出、理解后，再点击“揭晓读音与译文”。网站不会自动判定唱得是否正确，由学习者对照答案选择“我会了”或“还要再练”。

“我会了”会更新这首歌的掌握进度；“还要再练”会将该句加入复习清单。点击页眉“复习”可查看所有待复习句，点击任意一项可从该句开始练；练会后会自动移出清单。没有音频时仍可练习读音和词义，但揭晓读音需要本地标注服务运行。

## 网页导入自己的歌曲

适合使用者在网页上导入，歌曲保存于当前浏览器，不会放进项目的 `geci/` 或 `song/` 文件夹。与下方“项目文件夹导入”是两条独立路径。

1. 在“歌曲库”点击 **导入歌曲**。
2. 选择一个包含逐句时间戳的 `.lrc` 文件。
3. 选择对应的音频文件（MP3、M4A、WAV、OGG、WebM 等）。
4. 等待歌词解析和封面候选出现，检查歌名、歌手、逐句日文、中文译文及时间戳；需要时可直接修改、添加或删除句子。封面可从多平台候选中选一张，或上传本地图片、填写链接、使用默认封面。导入后也可在歌曲库更换。
5. 选择 **直接导入** 或 **导入并在后台生成**，确认保存。直接导入后可立即学习；后台模式会先保存歌曲并关闭导入窗口，再分批生成 AI 解析，不要求停留在导入界面。关闭网页时任务暂停，下次打开后尝试续做。

导入的歌词数据和音频保存在当前浏览器的 IndexedDB：刷新页面后仍可使用，但换浏览器、清除站点数据或清除浏览器存储后会消失。不会按原文件路径读取，也不会将歌词文件或音频文件上传到远程服务器。歌词文本会发送给本机 FastAPI 服务生成读音；选择后台生成或在学习页主动生成解析时，歌词及相邻句、LRC 译文会分批发送给当前配置的 AI 服务，可能产生 API 调用费用。查找封面时，歌曲名和歌手名会发送给上述音乐平台；详见下方“隐私与数据”。

LRC 的每句应带有时间戳，例如：

```lrc
[00:12.40]夏の空を見上げる
[00:16.20]仰望夏日的天空
[00:16.20]君に言葉を届けたい
[00:20.50]想把话语传达给你
```

中文译文放在对应日文歌词的下一行即可；即使译文的时间戳与下一句日文相同，也会按相邻顺序配对。只有日文的 LRC 也能导入，只是不显示中文释义。旧版已导入的歌曲若没有译文，需要用原 LRC 和音频重新导入一次。

LRC 中的歌名、歌手资料行不会作为歌词参与读音标注或 AI 全曲复核；歌曲正文里单独出现的同名歌词仍会保留。已经导入的旧歌曲无需重新导入，页面会自动隐藏这些资料行。

每句歌词右侧播放和掌握按钮下方的 **查看解析**，会在当前句下方展开已缓存的整句 AI 讲解；再次点击即可收起，逐句练习时也可在答案下方展开。导入时若 AI 服务未配置、限流或中途失败，歌曲仍会保存；学习页可点击 **生成剩余解析** 续做。以前导入的歌曲和项目内置歌曲也可在学习页主动批量生成；尚未缓存的单句可以点击 **生成解析**。缓存只对原句相同的歌词有效，选中某个词或片段的现有 AI 讲解仍是按需请求。

## 数据备份与恢复

在右上角 **设置 → 数据管理** 点击 **导出备份**，浏览器会下载一个 `.uta-backup` 文件。它包含网页导入歌曲的歌词、原声音频、歌曲资料，以及已掌握句子、复习清单、收藏、读音与词义修正、自动注音缓存、AI 复核记录和已生成的整句解析；内置歌曲的歌词与音频仍由项目本身提供。备份只在本机浏览器生成，不会上传到服务器。

换浏览器或清除站点数据前，请先保存这个文件。需要恢复时，在 **设置 → 数据管理** 点击 **导入备份** 并选择文件，检查预览后确认；歌曲库的“数据管理”按钮也可进入该面板。恢复会**覆盖当前浏览器**里已有的网页导入歌曲和学习记录，不会把两份数据合并；因此建议恢复前先导出当前数据。恢复完成后页面会自动刷新。备份包含原声音频，请妥善保管，不要在没有授权的情况下分享或公开发布。AI 配置与 API Key 不包含在学习备份中，换浏览器后需单独配置。

1. 把 `.lrc` 文件放进 `geci/`。
2. 把同名音频文件放进 `song/`，例如 `歌手-歌名.lrc` 对应 `歌手-歌名.mp3`。
3. 执行：

### LRC 编码与识别限制

网页导入和文件夹同步共用 `src/lib/lrcEncoding.js`：先严格解码 **UTF-8（兼容 BOM）**，失败后依次尝试 **GB18030、GBK**。没有替换字符容错的静默回退；解码失败、检测到替换字符 `�` 或不支持的 UTF-16 BOM 时，会明确提示文件名和处理办法。UTF-8 BOM 文件如果损坏，也不会再被当成 GBK 读取。

自动识别有局限：有些字节在不同编码下都合法，不能保证识别所有编码，也不能自动恢复已经被保存为乱码的文本。建议用文本编辑器按正确的原编码打开，确认日文和中文正常后，**另存一份 UTF-8 的 `.lrc`**，保留原件。程序只读取原始 LRC，不会覆盖或转换它们。任一文件解码失败时，文件夹同步返回失败并保留上次生成的数据，不会生成半份歌曲库；修正问题文件后再同步。

| --- | --- | --- |
| 网页导入 · 当前浏览器 | 浏览器 IndexedDB，学习记录在 Local Storage | 点击卡片上的“删除”，移除该歌曲在当前浏览器中的歌词、音频及学习记录；不删除电脑上的原始文件 |
| 来自项目文件夹 | `geci/` 歌词、`song/` 音频及生成的歌曲列表 | 将相应 LRC 移出 `geci/`，运行 `npm.cmd run lyrics:sync` 并刷新网页；构建部署版需重新构建并部署 |
| 内置原创示例 | `src/data/demoSongs.js` | 随项目提供，不提供网页删除入口；开发者可修改示例配置 |

网页不会删除服务器或项目文件夹中的文件。只移出 LRC 会移除歌曲列表项，**不会删除 `song/` 中的音频**；如不希望它继续被打包，请自行将对应音频移出 `song/`，并在部署时移除旧产物中的音频文件。

### 已有乱码歌曲如何恢复

1. 先在“设置 → 数据管理”导出学习备份，保留原始 LRC 和音频，不要清空浏览器存储。
2. **来自项目文件夹**：更新到本次修复版本；原件为正确的 UTF-8、GBK 或 GB18030 时，无需改写文件，执行 `npm.cmd run lyrics:sync` 后刷新即可。部署版重新构建并部署。如果原件本身已经乱码，请找回正确原件或按上方方法另存 UTF-8，再同步。
3. **网页导入**：已保存的歌词不会因解码器升级而被重新读取。如果这份记录已经乱码，先重新导入正确的 LRC 与音频，检查预览，确认新歌曲正常后再删除那首旧的乱码记录；新导入会有独立的学习进度，不会覆盖其他歌曲。
4. 更新后的文件夹歌曲使用基于文件名的稳定 ID，增删其他文件不会让记录串歌。旧版按排序生成的 ID，仅在旧缓存与整首歌词逐句内容及编号完全一致、且匹配唯一时自动迁移；无法确认归属的旧记录仍保留在本地备份数据中，但不会强行应用。文件改名会视为另一首歌曲，建议保持原文件名。
5. 注音缓存和手动读音修正按句子编号、原文及词素内容核对，不再只比较句数。内容或编号变化的行不再沿用旧修正和掌握状态；仍能核对一致的行保留。歌曲正文改变后，其旧 AI 复核及整句解析失效，可重新生成；仅修改时间戳不会清除读音修正。无法确认的乱码版本记录可能需要重新校对，但不会清空其他歌曲的数据。

内置歌曲和网页导入歌曲会尝试按歌名、歌手搜索封面；如需为内置歌曲指定封面，可在 `src/data/songArtwork.js` 中按 `sourceFile` 配置公开封面 URL 与来源页链接。专辑封面通常受版权保护。

## 本地完整日中词典（可选，但推荐）

项目不提交约 662 MB 的解压词典数据库。没有它时仍能自动注音，但可显示的中文释义会较少。

1. 从 [Tomoshi Dictionary Open Data Layer 的发布页](https://github.com/tomoshi-app/tomoshi-dict-data/releases) 下载 `tomoshi-dict-open.db.zst`。
2. 放到 `server/data/tomoshi-dict-open.db.zst`。
3. 在 `server/` 目录执行：

   ```powershell
   @'
   from pathlib import Path
   import zstandard as zstd

   source = Path('data/tomoshi-dict-open.db.zst')
   target = Path('data/tomoshi-dict-open.db')
   with source.open('rb') as reader, target.open('xb') as writer:
       zstd.ZstdDecompressor().copy_stream(reader, writer)
   '@ | .\.venv\Scripts\python.exe -
   ```

首次查询会使用该本地 SQLite 数据库；不会把歌词或查词内容发送给词典服务。公开部署、修改或重新分发词典数据时，请遵守 [THIRD_PARTY_DATA_NOTICES.md](THIRD_PARTY_DATA_NOTICES.md) 中的署名与许可要求。

## 设置与 AI 服务

右上角 **设置** 提供“注音显示”“数据管理”和“AI 服务”。歌曲库中的“数据管理”也会打开同一面板。

### 平假名与罗马音

进入 **设置 → 注音显示**，选择 **平假名**（默认）或 **罗马音**，立即生效并自动保存在当前浏览器。歌词上方的注音、下方读音行、逐句练习答案、词语详情、AI 复核建议及 AI 返回的独立读音字段会跟随切换；日文歌词原文、词典形和解释正文不改写。“原文”和“遮住练习”模式仍然隐藏注音。

罗马音由本地 [WanaKana](https://github.com/WaniKani/WanaKana) 根据已有读音转换，不需要联网或调用 AI。例如 `ゆめ → yume`、`がっこう → gakkou`、`コーヒー → koohii`、`しんよう → shin'you`。长音保留为连续元音；根据词性识别出的助词「は／へ／を」显示为 `wa／e／o`，手动修正优先。它不会重新判断汉字读音，也不能表达所有歌唱细节；自动读音错误时仍需校对。

校对输入框继续使用假名，罗马音模式下附带实时转换预览；保存假名修正后，对应歌词注音和读音行的罗马音会立即跟随更新，无需重新导入歌曲。切换显示不会把原始注音或手动修正改存成罗马音。偏好会包含在学习备份中；旧备份没有这项设置时默认使用平假名。

### 网页配置 AI 服务

默认使用服务端已有的 DeepSeek 配置；服务端密钥不会返回浏览器。要使用自己的服务，取消勾选“使用服务端默认配置”，填写供应商名称、接口类型、API 地址、API Key 和模型名称。支持 DeepSeek，以及 OpenAI Chat Completions 兼容服务（包括提供此接口的本地模型）；暂不支持原生 Anthropic Messages 或仅提供 Responses 的接口。

- API 地址可填写基础地址（如 `https://api.openai.com/v1`）或完整的 `/chat/completions` 地址；模型 ID 按供应商说明填写。
- 远程地址使用 HTTPS；本机与局域网 IP 支持 HTTP。本地服务地址由 Python 后端访问。无需鉴权的服务可留空 Key；不会借用服务端 Key。
- 点击 **测试连接** 会发送一条短文本验证模型与 JSON 输出，可能产生少量调用费用；测试不会自动保存，请再点 **保存设置**。
- 不支持 `response_format` 参数的兼容服务可以关闭“JSON 输出模式”，但模型仍需返回合法 JSON。
- API Key 默认保存在当前标签页会话；勾选“在此浏览器记住 API Key”后才持久保存（明文）。密钥随 AI 请求发给网站后端转发，不写入服务端配置，也不进入学习备份。部署时应使用可信的后端连接。
- 更换 API 地址或快速预设会清空待填密钥，需为新服务重新填写；“清除配置”删除浏览器保存的配置与密钥并恢复服务端默认。
- 配置生效于后续读音复核、整句解析、片段讲解；已保存的解析仍然保留。不同浏览器的设置互不覆盖。

当前后端允许请求指定 AI 服务地址，面向本机和受信任的使用环境。不要直接将其作为无需登录的公共转发服务暴露到互联网；公开部署前需补充鉴权、出站目标限制及相应的额度控制。

接口参考：[DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[OpenAI Chat API](https://developers.openai.com/api/reference/resources/chat)。

### 可选：服务端默认 DeepSeek 配置

默认读音完全由本地 SudachiPy 生成。选择导入后后台生成、在学习页生成整句解析、执行“AI 复核全曲”或片段“AI 解释”时，才会向当前配置的 AI 服务发送必要的歌词上下文。没有配置 Key 时歌曲仍能导入，但整句解析暂时无法生成。

在 `server/` 下复制 `.env.example` 为 `.env`：

```powershell
Copy-Item server\.env.example server\.env
```

编辑 `server/.env`：

```ini
DEEPSEEK_API_KEY=你的 DeepSeek API Key
DEEPSEEK_MODEL=deepseek-flash
```

`.env` 已被 Git 忽略，绝不要把 API Key 写进前端代码、截图或公开仓库。

## 网页端隐私与数据

| 内容 | 保存位置 | 是否上传 |
| --- | --- | --- |
| 学习进度、读音与词义修正 | 浏览器 Local Storage | 否 |
| 网页导入的 LRC 与音频 | 浏览器 IndexedDB | 否 |
| 自动注音、词典释义 | 本机 FastAPI 服务 | 否 |

| 封面检索所需的歌名、歌手名 | 电脑网页经本机服务、Android 直接访问 Apple Music、网易云音乐、QQ 音乐、酷狗音乐 | 是，仅打开封面选择器或旧版自动补查时 |
| 自行上传的封面 | 压缩后保存在本机歌曲资料或当前设备的封面选择中，可随学习备份迁移 | 不上传原始图片到音乐平台；主动进行电脑传歌时会携带压缩图 |
| AI 整句解析 / 复核 / 片段讲解 | 当前配置的 AI 服务（确认导入或主动点击后） | 会发送所需歌词上下文与已有译文；不会发送音频 |

## 项目结构

```text
src/                   React 网页
  data/                自动生成歌曲数据、封面映射
  lib/                 注音 API、AI API、本地歌曲 IndexedDB
  assets/              原创主页背景图
server/                FastAPI、SudachiPy、可选本地词典
geci/                  内置 LRC 歌词
song/                  内置音频
scripts/sync-lyrics.mjs
```

注音服务对共享的 Sudachi 分词器加锁，避免多个请求并发使用时发生借用冲突。回归测试覆盖歌词编码、记录迁移、备份、浏览器 AI 配置、服务端供应商边界及并发注音；测试不会实际调用付费 AI 接口。
