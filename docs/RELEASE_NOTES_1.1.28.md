# UTA Windows 1.1.28 更新公告

这是相对上次上传的 **Windows 1.1.6** 的累计更新，适用于 Windows 10 / 11 x64。

## 新增与改进

- **跟唱播放器**：从任意歌词句开始连续播放，歌词随进度滚动；支持自定义图片、纯色或默认背景，切换注音和译文显示。跟唱界面扩展到标题栏以下的整个工作区。
- **更细致的听读练习**：连续选句可按准确时间戳慢放，设置 3 次、5 次或无限循环以及 1–3 秒跟读间隔，也可使用“听一次→自己读→再听一次”。
- **歌词导入与编辑**：本地没有匹配歌词时可联网搜索 LRCLIB / UtaTen；导入前可分轨检查原文、译文和罗马音，修正时间戳与插句。歌词自带假名优先使用。新增逐句右键编辑与自定义分词。
- **阅读与界面**：假名和罗马音可按词对应显示；歌词、假名、词下罗马音和译文可分别调整字号。新增四套主题色、可调整并记住宽度的分栏、播放与选句快捷键，歌曲库列表更易阅读。
- **AI 复核与任务**：AI 可提出读音和词典分词建议，允许采纳、跳过及恢复；任务面板集中显示导入、注音、AI 解析的进度、失败原因、重试和取消。批量 AI 解析需要用户主动勾选。
- **数据保护**：编辑译文或时间不再清除整首学习记录；改原文只影响相应句子。支持编辑撤销与重做、未保存退出提示，以及恢复备份前自动保存快照。播放器只保留正常速度和慢放。

## 下载与升级

下载 `UTA-1.1.28-Windows-x64.zip`，完整解压并运行 `UTA-Windows-x64/UTA.exe`。升级旧版时先退出 UTA，备份并保留原目录中的 `uta-data` 文件夹，再替换程序文件。ZIP 不包含歌曲、学习记录或 API Key；仅复制 EXE 无法运行。当前版本不在程序内自动安装更新。
