# UtaTen 注音提取验证

2026-10-14：保留单页研究工具；安卓 1.3.0 已加入 UtaTen 搜索与注音导入。以下命令行说明仍适用于单独验证和导出。

## 已验证的页面结构

- 歌词正文位于 `.lyricBody`，假名版位于 `.hiragana`，罗马音版位于 `.romaji`。
- 注音单元通常为 `.ruby` 中的 `.rb`（原词面）与 `.rt`（读音）；解析器同时兼容原生 HTML ruby 标签。
- 两套内容存在于普通 HTML 中；该样本不需要执行 JavaScript、登录或绕过验证。
- 按原词面匹配两套歌词行，各自保留分词，不因为两套注音的词界不同而按位置强行拼接。原文与注音分开保存，不把注音当作歌词中的额外词。
- 单页实测《ステラブリーズ》取得 31 个非空歌词行、89 处假名注音、31 行罗马音及 207 个罗马音单元；这些是页面标注单元，不等于词典分词数量。
- 该样本没有用于跟唱的逐句时间轴，工具不伪造时间戳，不把无时间轴文本命名为 LRC。

## 运行

在项目根目录，使用项目现有 Python 3.12 虚拟环境，不需要额外安装依赖：

```powershell
$env:PYTHONIOENCODING = 'utf-8'
# 只验证一个歌词页，打印统计；不保存、打印完整歌词。
& .\server\.venv\Scripts\python.exe -B .\scripts\utaten_lyrics.py 'https://utaten.com/lyric/mi17042622/'
```

对自己有权使用的页面内容，可指定输出文件名前缀；输出建议放在 Git 忽略的 `.tools` 目录：

```powershell
& .\server\.venv\Scripts\python.exe -B .\scripts\utaten_lyrics.py 'https://utaten.com/lyric/歌曲编号/' --output '.tools/utaten/选定歌曲'
```

会生成：

- `选定歌曲.uta-lyrics.json`：原文、完整假名、完整罗马音、原文字词与注音的对应关系、来源链接。`timed` 为 false。
- `选定歌曲.txt`：按句排列括号注音原文、假名和罗马音，便于人工查看；不含时间戳，需要跟随播放时须补充时间轴。安卓内推荐直接使用 UtaTen 搜索导入，保留结构化注音。

可用 `--html 本机页面.html` 解析用户自行保存的页面，不联网。工具只访问单个 HTTPS UtaTen 歌词网址，限制页面大小、超时和重定向，不提供全站遍历或绕过验证。

导出功能用原创测试短句验证，仓库不包含抓取的整首歌词。联网验证仅保存不含歌词的统计。

## 与 UTA 导入的关系

现有应用采用带时间轴的歌词。接入 UtaTen 时适合作为已有 LRC 的注音补充来源：先由用户选择同曲同版本，再严格匹配原文，把来源注音附着到已有时间轴；版本不同、缺行或对齐不明确时需要预览确认，不能直接按行号覆盖。网站自带假名可用于避免把罗马音反推假名时产生歧义，人工校正仍由用户决定是否更改。

本地应用开发版可直接导入普通 TXT 和这里的研究 JSON，音频可稍后补充；无时间轴时仅阅读和学习，补音频后仍须由用户补齐时间轴才能逐句试听或跟唱。正式 1.2.0 尚不支持此流程。
