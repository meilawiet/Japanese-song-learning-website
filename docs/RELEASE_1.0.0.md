# UTA 1.0.0

UTA 首个公开版本，同时提供安卓应用与电脑网页。

## 安卓端

- 学习、复习、我的三个入口；逐句学习与连续跟唱，支持慢速播放和最近学习。
- 本地音频/LRC 导入、音频名称识别、歌词搜索；可直接导入或后台生成 AI 解析。
- 歌曲库网格/列表、歌曲信息编辑、歌词与人工注音校正。
- 多平台封面搜索、自定义封面与离线保存。
- 离线假名/罗马音注音，问 AI 上下文与历史对话，DeepSeek 联网查询可选开启。
- 本地昵称、头像裁剪、GIF 头像；WebDAV 完整数据备份。
- 自动备份默认关闭，默认检查周期 24 小时；应用关闭/后台期间暂停，返回前台后补做到期检查。云端恢复须确认，API Key 默认排除。
- 启动检查更新，是否下载由用户决定。

下载安装附件 **UTA-Android-1.0.0.apk**，支持 Android 7.0 及以上，已在 Android 13 手机上验证覆盖安装与启动。可通过同名 SHA-256 校验文件核对下载完整性。

沿用此前本地测试版的签名，内部版本编号继续递增。旧签名测试版可覆盖安装；开发调试版包名不同，数据独立。卸载或清除数据前请先备份。

## 网页端

仓库源码提供 Windows 一键安装与启动，以及 LRC/音频导入、逐句练习、复习、后台 AI 解析、封面选择、浏览器本地备份和电脑传歌功能。安装与使用见仓库 README。

两端目前功能存在差异，网页后续开发入口见 WEB_APP_DEVELOPMENT_HANDOFF.md。跨平台账号及数据互通尚未开放。

## 使用说明

- 不附带商业歌曲；请自行准备有权使用的音频与歌词。
- 已导入歌曲与离线注音可断网使用；搜索、AI、WebDAV 和更新需网络。
- AI 测试与解析、联网查询可能产生费用；按需配置自己的服务。
- 本次仅发布 1.0.0 新安装包，旧测试安装包保留在本地备份，不公开上传。
