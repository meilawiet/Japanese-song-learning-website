# UTA · 日语歌词发音学习站

一个面向有一定日语基础的歌词学习网站。把歌曲按 LRC 时间轴拆成逐句练习：先听原声，再看读音、查词义，最后跟唱和校对。

> 当前版本适合本地运行和邀请朋友试用。歌词、音频和专辑封面可能受版权保护；公开部署前请确保自己拥有相应授权。

## 能做什么

- 导入带时间轴的日语 LRC 与歌曲音频；保存前可预览并校对歌词、译文、时间戳和封面。
- 根据每句时间戳播放原声，播放起点提前 0.5 秒；支持 `1× / 0.75× / 0.5× / 0.25×` 慢放。手机上点击整句歌词区域即可播放，再点暂停，暂停后再点从句首重播；掌握状态和解析按钮仍各自独立。
- 如果 LRC 含中文译文，会在对应日文歌词下显示；每句可切换“已掌握 / 未掌握”，歌曲库同步显示掌握进度。
- 逐句练习模式先隐藏读音和译文，听原声、自行回忆后再揭晓；选“还要再练”的句子自动进入复习清单。
- 用 SudachiPy 生成逐词假名读音；可手动校正，修正结果优先显示。
- 提供原文、注音（平假名或罗马音）、遮住读音三种学习模式。
- 设置中可切换平假名或罗马音注音，即时替换读音展示；偏好保存在本地并随学习备份迁移。
- 本地日中词典提供常用中文释义和词形信息；纯假名同形词会按词性优先消歧。
- 鼠标拖选歌词片段后可请求 AI 语境讲解；AI 只给建议，不会自动修改学习内容。
- 网页导入歌曲时分批预生成每句的 AI 解析；歌词下方可立即查看整句意思、关键表达与语法，选中片段的单独讲解仍可使用。
- AI 复核整首歌曲中可能不合理的读音，并逐条供用户确认。
- 学习进度、读音修正、手工词义和网页导入歌曲都保存于浏览器本地。
- 可从“设置 → 数据管理”导出单个本地备份文件，并在另一浏览器恢复歌曲、音频、读音修正与学习进度。
- “设置 → AI 服务”支持服务端默认配置或自定义 Chat Completions 兼容服务，并可测试连接；密钥不进入学习备份。
- 内置日漫抒情风格主页和独立歌曲库；可按歌名或歌手检索、切换歌曲，并删除网页导入的歌曲。
- 导入或更换封面时可在 Apple Music、网易云音乐、QQ 音乐、酷狗音乐的候选中选择，也可上传本地图片、填写图片链接或使用默认封面；网页和 Android 均可使用。

## 效果预览

启动后访问 `http://localhost:5173`，可先用仓库内的原创短句练习，也可在“歌曲库”使用“导入歌曲”选择一份 `.lrc` 与对应音频文件。

## Android 初版（开发测试）

项目已加入 Capacitor Android 工程。Android 13 真机已验证早期版本的安装、LRC 与音频导入、逐句播放、学习进度恢复及电脑网页传歌；`1.8-test` 按用户要求跳过真机验证。手机读音由 APK 内置的 Kuromoji 词典离线生成，不要求电脑在线；AI 由手机直接连接用户在设置中填写的 Chat Completions 服务。安卓端启动后进入“学习”，底部固定“学习 / 复习 / 我的”三个入口；学习页提供“逐句学习”和“跟唱练习”，复习页保留现有入口，“我的”连接歌曲库与设置。逐句学习保留点击整句播放、暂停和从句首重播；跟唱练习可从头连续播放，或点击任意一句后从该处持续播放到歌曲结束。两个练习页显示放大的当前歌曲封面，学习入口分别展示最近逐句学习和最近跟唱的歌曲；练习页顶部不再显示“返回学习”，仍可用系统返回手势或底部导航。Android 测试包只包含仓库里的原创示例，不会自动打包本机 `song/` 和 `geci/` 里的歌曲。

开发时需先安装 Node.js、Android Studio、Android SDK 和 Java 21，连接已开启 USB 调试的 Android 手机。在项目根目录运行：

```powershell
npm.cmd install
npm.cmd run android:sync
cd android
.\gradlew.bat assembleDebug
```

调试安装包位于 `android/app/build/outputs/apk/debug/app-debug.apk`，可运行 `adb install -r android/app/build/outputs/apk/debug/app-debug.apk` 安装。调试版包名以 `.dev` 结尾，可与正式签名版并排安装，二者数据独立。每次修改网页界面后，先重新运行 `npm.cmd run android:sync`，再构建新包。供手机直接安装测试的签名 APK 位于 `.tools/releases/UTA-Android-1.8-test-release.apk`；该目录仅存在于本地，不随 Git 提交。

Android 应用图标取自用户提供的原图 `android/icon-source.png`。修改原图后运行 `./scripts/generate-android-icon.ps1`，会生成不同像素密度的普通、圆形和自适应图标；透明区域使用深色背景。图标文件属于用户提供的素材，公开发布前请确认使用权。

安卓界面字体使用用户提供的 `YanZhenQingDuoBaoTaBei.ttf`，存放在 `src/assets/fonts/`；仅安卓端启用，电脑网页仍使用原有字体。为使 Android WebView 能加载，已将字体内部 `vhea` 表版本从 `0x00010001` 修正为标准的 `0x00010000`，字形保持原样。字体内嵌名称标注“非商业使用”，公开发布前应核对使用许可。`1.5-test` 已包含这款字体和浅色歌曲库；歌曲库可在封面网格与歌名列表间切换，长按封面或点击列表三点菜单可删除本地歌曲、更换封面。内置原创示例不在安卓歌曲库中显示。安卓侧滑与系统返回键会先关闭当前弹窗，再返回上一页面；根页面返回时应用进入后台。

当前源码与签名安装包的本地导入可选“直接导入”或“导入并在后台生成 AI 解析”。直接导入后可在学习页按需生成整句解析；后台模式会先保存歌曲并关闭导入窗口，再逐批生成，应用被关闭时未完成任务会在下次打开时续做。选中音频后会优先读取 MP3 的 ID3 歌名与歌手标签，其他文件或无标签文件按文件名推断，并自动在 LRCLIB 搜索同步歌词；用户需核对并选用正确结果。导入界面另提供 Toomic/MusicEnc、歌曲宝、爱歌词网和世纪音乐网的网页搜索入口；网站内下载的音频或歌词需返回应用用文件选择器导入。各网站未提供统一可用的音频下载接口，因此应用不会自动抓取并保存音频。安卓歌曲库长按封面或点列表三点菜单可编辑本机导入歌曲的歌名、歌手、每句歌词和时间轴，并可重新上传音频或整份 LRC；更改歌词后会清除该曲旧的逐句掌握与解析结果，其他歌曲数据保留。

### 安卓个人资料、云备份与更新

安卓端在“我的 → 设置”中提供个人资料、数据管理、AI 服务和关于四个分类。个人资料支持裁剪静态头像、保留 GIF 动画及修改昵称，头像文件限制 10 MB；“我的”页点击头像可放大查看。逐句学习的“问 AI”支持本地历史对话和歌词上下文，联网查询开关与 AI 服务设置共用偏好，并提示可能增加费用。

数据管理提供通用 HTTPS WebDAV 云备份，包含歌曲与音频、封面、歌词、学习进度、头像昵称、对话和 AI 配置。默认不上传 API Key；选择包含密钥时会显示警告并要求确认。WebDAV 密码在手机系统加密保存，不放入备份。上传保留新备份，下载后先预览，确认恢复会替换本机数据。安卓暂时隐藏网站数据导入导出入口。

自动同步默认关闭，检查间隔默认 86400 秒（24 小时），允许 0 或正整数；60 表示每分钟，0 停止定时检查。应用打开时按周期检查本机变更并上传，关闭期间暂停，重新打开后补做已到期检查。云端数据恢复需用户确认。

“关于 → 检测更新”读取本仓库的官方 GitHub Release；每次启动也会自动检查，发现新版本后由用户选择下载。发布用于更新的版本需要使用 `v1.10.0` 等数字版本标签，并附带正式 APK 文件；未发布安装包时显示暂无可用更新。更新检查只读取公开版本信息。

### 歌曲封面

在网页或 Android 的 **歌曲库 → 导入歌曲** 中，填好歌名和歌手后会显示多个平台的候选封面，点选所需图片再确认导入。已有歌曲可在歌曲卡片点 **更换封面**；项目文件夹歌曲和内置示例也支持当前设备上的封面选择。若结果不匹配，可上传不超过 10 MB 的 JPG、PNG 或 WebP 图片，填写 HTTPS 图片链接，或选默认封面。在线选择的封面在确认保存时会下载、裁为方形并压缩为本机 JPEG 数据，断网后仍可显示；旧版本已保存的在线封面在联网启动时会尝试迁移，失败时保留原链接供以后重试。图片下载失败会阻止保存新选择并显示错误，用户可改选其他候选或上传本地图片。学习备份会包含已下载的封面，电脑传歌也会带上已导入歌曲的封面。

电脑网页通过本机服务检索各平台；Android 直接检索，不要求电脑在线。检索会向各平台发送歌曲名和歌手名，不发送歌词或音频。平台接口可能变动或限制访问，单一来源失败不会阻止选择其他来源和本地图片。候选图片来自对应平台，公开使用前请核对授权；Apple Music 使用其 [iTunes Search API](https://developer.apple.com/library/archive/documentation/AudioVideo/Conceptual/iTuneSearchAPI/)。

### 手机注音与 AI（方案 C）

- 手机安装包内含压缩日语词典；首次打开一首尚未注音的歌时需要加载词典，之后在当前进程复用。无网络时仍可生成读音，也可手动校正。它与电脑端 SudachiPy 使用不同词典，个别分词和读音可能不同，请结合原唱确认。
- 在手机 **设置 → AI 服务** 选 DeepSeek 或填写自己的 Chat Completions 兼容接口，输入 API Key 和模型名称，先点 **测试连接**，成功后点 **保存设置**。手机没有电脑网页的服务端默认 Key；无需鉴权的局域网模型可留空 Key。公网地址要求 HTTPS，局域网 IP 可使用 HTTP；`localhost` 指手机本身，不能代替电脑地址。
- 不勾选“在这部手机上记住 API Key”时，Key 仅保留在本次应用会话；勾选后由 Android Keystore 加密保存。Key 不进入学习备份，也不写入 APK。手机会把测试文本或请求解析的歌词文字直接发给所选 AI 服务，音频不会发出；可能产生服务费用。导入时会尝试分批生成逐句解析，AI 未配置或失败时歌曲仍会保存，可在学习页补做。读音复核和选词讲解按需请求。
- 真机已用局域网模拟的 Chat Completions 服务验证连接测试、读音复核、逐句解析和选词讲解的数据路径。真实供应商需要用户自己的有效 API Key，是否可用还取决于其模型权限、网络和额度。

### 从电脑网页把已有歌曲导入手机

手机“歌曲库 → 导入歌曲”现在可以选择“从手机文件导入”或“从电脑网页导入”。前者继续使用手机系统的文件选择窗口；后者读取**电脑浏览器中通过网页导入并保存的歌曲**，包括音频和这些歌曲的学习记录。它不会自动读取项目文件夹 `song/` 或 `geci/` 中的文件，也不会把歌曲上传到互联网或 GitHub。

1. 在电脑上双击 [启动 UTA 手机传歌.cmd](../启动%20UTA%20手机传歌.cmd)。它会打开电脑网页并启动临时传歌服务；保持命令窗口打开。
   两个中文名称的启动脚本现在共用同目录下的 `start-uta-website.cmd`；复制或移动项目时请保留整个项目文件夹。
2. 在电脑网页的“歌曲库”点击“共享到手机”。网页会读取它保存的歌曲，显示 **USB 和同一 Wi-Fi 共用的 4 位数字连接码**。若网页没有保存过歌曲，请先在该网页导入。
3. 在手机 UTA 中打开“歌曲库 → 导入歌曲 → 从电脑网页导入”，选择 USB 数据线或同一 Wi-Fi。USB 方式需要手机开启 USB 调试、授权这台电脑并保持数据线连接；Wi-Fi 方式需要两台设备处于同一网络，手机会自动查找电脑。建议电脑连接手机热点，查找电脑成功率更高。如果 Windows 防火墙询问是否允许访问，请只允许可信的专用网络。
4. 输入电脑网页显示的 **4 位数字连接码**，点击“检索电脑网页歌曲”，再全选或逐首勾选并导入。音频和所选歌曲的学习记录会保存在手机中；手机已有的同一首歌不会被覆盖。

连接码和电脑上的临时歌曲文件会在 30 分钟后失效；也可在电脑网页点击“结束本次共享”。请只在可信的局域网内开启 Wi-Fi 传歌，不要将连接码告诉其他人；连续输错 5 次会暂时限制尝试。关闭传歌命令窗口会立即停止连接。若 Wi-Fi 自动找不到电脑，可点“找不到电脑？手动填写地址”，输入电脑网页显示的局域网地址；还可检查两台设备是否在同一网络以及电脑防火墙。USB 方式可检查数据线和 USB 调试授权。电脑传歌服务的自动发现功能使用 Python `zeroconf` 包，安装或更新项目依赖时运行 `server\.venv\Scripts\python.exe -m pip install -r server\requirements.txt`。

## 一键安装（Windows）

下载或解压完整项目后，双击项目根目录的 [安装 UTA 网站.cmd](../安装%20UTA%20网站.cmd)。脚本会检查电脑里符合要求的 Node.js、Python；如果缺少，会下载便携版 Node.js 24.21.0 或项目内的 Python 3.12，创建 `server/.venv`，安装前端与后端依赖。安装结束后双击 [启动 UTA 网站.cmd](../启动%20UTA%20网站.cmd)。已安装过时可以再次运行安装程序，以补齐或更新依赖；不会删除网页中保存的歌曲和学习进度。

脚本只向项目内的 `.tools/`、`node_modules/`、`server/.venv/` 和各缓存目录安装或下载文件，不改系统 PATH，也不要求管理员权限；如复用电脑里已经安装的 Node.js/Python，也不会向它们的全局目录安装包。请确保项目所在磁盘有足够空间，首次安装需要访问 Node.js 官网、GitHub、npm 与 Python 包索引。网络或代理阻断时，脚本会停下并显示出错步骤，可检查网络后重试；不会自动安装可选的大型日中词典。Windows 以外的系统请按下方手动步骤安装。

旧版安装脚本若在下载 Node.js 后提示 `Downloaded Node.js is not usable`，更新项目文件后直接重新双击安装程序即可；已验证的下载缓存会复用，不用手工删除 `.tools/`。若仍失败，请保留安装窗口中显示的完整报错，方便定位解压位置或系统兼容问题。

## 手动安装与启动

在项目根目录打开 PowerShell：

```powershell
# 1. 安装前端依赖到当前项目的 node_modules
npm.cmd install

# 2. 创建项目内的 Python 虚拟环境
py -3 -m venv server\.venv

# 3. 安装后端依赖到项目内虚拟环境
server\.venv\Scripts\python.exe -m pip install -r server\requirements.txt

# 4. 同时启动网页与本地标注 API
npm.cmd run dev
```

打开：

- 网页：`http://localhost:5173`
- 本地 API：`http://127.0.0.1:8000`

生产构建校验：

```powershell
npm.cmd run build
npm.cmd run test:backup
node --test tests/aiSettings.test.mjs
npm.cmd run test:lyrics
npm.cmd run test:readings
node --test tests\startup.test.mjs
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests\setup.ps1
server\.venv\Scripts\python.exe -m unittest discover -s server\tests
```

所有 npm 依赖放在项目的 `node_modules/`，Python 依赖放在 `server/.venv/`，不会安装到系统全局目录。使用手动步骤时，`npm.cmd` 和 `py` 需事先可用；如果它们没有安装，请使用上方的一键安装程序。

### 以后不用输入命令

首次完成上述安装后，直接双击项目根目录的 [启动 UTA 网站.cmd](../启动%20UTA%20网站.cmd)。它会自动识别安装程序放在项目内的 Node.js，启动本地服务并打开浏览器。不要关闭标题为 `UTA local server` 的命令窗口；关闭它即可停止网站。Windows 下本地 API 不启用自动重载，修改后端 Python 代码后请关闭窗口再重新启动；网页前端仍保留 Vite 的热更新。

首次启动时显示“从 `geci` 同步 0 首歌曲”是正常的：公开仓库没有附带商业歌曲，网页会显示内置原创短句；也可进入“歌曲库”自行导入 LRC 和音频。如果浏览器打开后始终空白，先确认服务窗口里的 `[web]` 没有退出；若启动程序等待 30 秒后提示失败，请保留该窗口的完整报错。旧版本若显示 `WatchFiles detected changes in '.uv-cache'`，请更新项目文件并重新启动，勿把 `.uv-cache` 当作歌词文件处理。

## 逐句练习与复习

在“发音学习”页面点击“开始逐句练习”。练习卡片先只显示日文原句；可以播放该句原声并调整速度，尝试自己读出、理解后，再点击“揭晓读音与译文”。网站不会自动判定唱得是否正确，由学习者对照答案选择“我会了”或“还要再练”。

“我会了”会更新这首歌的掌握进度；“还要再练”会将该句加入复习清单。点击页眉“复习”可查看所有待复习句，点击任意一项可从该句开始练；练会后会自动移出清单。没有音频时仍可练习读音和词义，但揭晓读音需要本地标注服务运行。

## 网页导入自己的歌曲

适合使用者在网页上导入，歌曲保存于当前浏览器，不会放进项目的 `geci/` 或 `song/` 文件夹。与下方“项目文件夹导入”是两条独立路径。

1. 在“歌曲库”点击 **导入歌曲**。
2. 选择一个包含逐句时间戳的 `.lrc` 文件。
3. 选择对应的音频文件（MP3、M4A、WAV、OGG、WebM 等）。
4. 等待歌词解析和封面候选出现，检查歌名、歌手、逐句日文、中文译文及时间戳；需要时可直接修改、添加或删除句子。封面可从多平台候选中选一张，或上传本地图片、填写链接、使用默认封面。导入后也可在歌曲库更换。
5. 点击 **确认导入并生成解析**。歌词与音频先保存到当前浏览器，再分批调用当前配置的 AI 服务生成整句解析；请保持页面打开直至进度完成。

导入的歌词数据和音频保存在当前浏览器的 IndexedDB：刷新页面后仍可使用，但换浏览器、清除站点数据或清除浏览器存储后会消失。不会按原文件路径读取，也不会将歌词文件或音频文件上传到远程服务器。歌词文本会发送给本机 FastAPI 服务生成读音；点击“确认导入并生成解析”后，歌词及相邻句、LRC 译文会分批发送给当前配置的 AI 服务，可能产生 API 调用费用。查找封面时，歌曲名和歌手名会发送给上述音乐平台；详见下方“隐私与数据”。

LRC 的每句应带有时间戳，例如：

```lrc
[00:12.40]夏の空を見上げる
[00:16.20]仰望夏日的天空
[00:16.20]君に言葉を届けたい
[00:20.50]想把话语传达给你
```

中文译文放在对应日文歌词的下一行即可；即使译文的时间戳与下一句日文相同，也会按相邻顺序配对。只有日文的 LRC 也能导入，只是不显示中文释义。旧版已导入的歌曲若没有译文，需要用原 LRC 和音频重新导入一次。

LRC 中的歌名、歌手资料行不会作为歌词参与读音标注或 AI 全曲复核；歌曲正文里单独出现的同名歌词仍会保留。已经导入的旧歌曲无需重新导入，页面会自动隐藏这些资料行。

每句歌词右侧播放和掌握按钮下方的 **查看解析**，会在当前句下方展开已缓存的整句 AI 讲解；再次点击即可收起，逐句练习时也可在答案下方展开。导入时若 AI 服务未配置、限流或中途失败，歌曲仍会保存；学习页可点击 **生成剩余解析** 续做。以前导入的歌曲和项目内置歌曲也可在学习页主动批量生成；尚未缓存的单句可以点击 **生成解析**。缓存只对原句相同的歌词有效，选中某个词或片段的现有 AI 讲解仍是按需请求。

## 数据备份与恢复

在右上角 **设置 → 数据管理** 点击 **导出备份**，浏览器会下载一个 `.uta-backup` 文件。它包含网页导入歌曲的歌词、原声音频、歌曲资料，以及已掌握句子、复习清单、收藏、读音与词义修正、自动注音缓存、AI 复核记录和已生成的整句解析；内置歌曲的歌词与音频仍由项目本身提供。备份只在本机浏览器生成，不会上传到服务器。

换浏览器或清除站点数据前，请先保存这个文件。需要恢复时，在 **设置 → 数据管理** 点击 **导入备份** 并选择文件，检查预览后确认；歌曲库的“数据管理”按钮也可进入该面板。恢复会**覆盖当前浏览器**里已有的网页导入歌曲和学习记录，不会把两份数据合并；因此建议恢复前先导出当前数据。恢复完成后页面会自动刷新。备份包含原声音频，请妥善保管，不要在没有授权的情况下分享或公开发布。AI 配置与 API Key 不包含在学习备份中，换浏览器后需单独配置。

## 项目文件夹导入歌曲

适合在自己的本地开发环境维护歌曲库：

1. 把 `.lrc` 文件放进 `geci/`。
2. 把同名音频文件放进 `song/`，例如 `歌手-歌名.lrc` 对应 `歌手-歌名.mp3`。
3. 执行：

   ```powershell
   npm.cmd run lyrics:sync
   ```

脚本会生成 `src/data/songs.generated.js`。不要手工编辑这个生成文件。为避免意外公开受版权保护的歌词和音频，`geci/`、`song/` 和生成的歌曲数据默认不会提交到 Git。

开发服务运行时，同步后刷新网页即可查看。`npm.cmd run dev` 和 `npm.cmd run build` 也会先执行同步。生产环境使用的是构建时的歌曲列表，修改 `geci/` 后需重新执行 `npm.cmd run build` 并部署新的产物。

### LRC 编码与识别限制

网页导入和文件夹同步共用 `src/lib/lrcEncoding.js`：先严格解码 **UTF-8（兼容 BOM）**，失败后依次尝试 **GB18030、GBK**。没有替换字符容错的静默回退；解码失败、检测到替换字符 `�` 或不支持的 UTF-16 BOM 时，会明确提示文件名和处理办法。UTF-8 BOM 文件如果损坏，也不会再被当成 GBK 读取。

自动识别有局限：有些字节在不同编码下都合法，不能保证识别所有编码，也不能自动恢复已经被保存为乱码的文本。建议用文本编辑器按正确的原编码打开，确认日文和中文正常后，**另存一份 UTF-8 的 `.lrc`**，保留原件。程序只读取原始 LRC，不会覆盖或转换它们。任一文件解码失败时，文件夹同步返回失败并保留上次生成的数据，不会生成半份歌曲库；修正问题文件后再同步。

### 歌曲来源与删除规则

| 歌曲库标记 | 保存位置 | 如何删除或移除 |
| --- | --- | --- |
| 网页导入 · 当前浏览器 | 浏览器 IndexedDB，学习记录在 Local Storage | 点击卡片上的“删除”，移除该歌曲在当前浏览器中的歌词、音频及学习记录；不删除电脑上的原始文件 |
| 来自项目文件夹 | `geci/` 歌词、`song/` 音频及生成的歌曲列表 | 将相应 LRC 移出 `geci/`，运行 `npm.cmd run lyrics:sync` 并刷新网页；构建部署版需重新构建并部署 |
| 内置原创示例 | `src/data/demoSongs.js` | 随项目提供，不提供网页删除入口；开发者可修改示例配置 |

网页不会删除服务器或项目文件夹中的文件。只移出 LRC 会移除歌曲列表项，**不会删除 `song/` 中的音频**；如不希望它继续被打包，请自行将对应音频移出 `song/`，并在部署时移除旧产物中的音频文件。

### 已有乱码歌曲如何恢复

1. 先在“设置 → 数据管理”导出学习备份，保留原始 LRC 和音频，不要清空浏览器存储。
2. **来自项目文件夹**：更新到本次修复版本；原件为正确的 UTF-8、GBK 或 GB18030 时，无需改写文件，执行 `npm.cmd run lyrics:sync` 后刷新即可。部署版重新构建并部署。如果原件本身已经乱码，请找回正确原件或按上方方法另存 UTF-8，再同步。
3. **网页导入**：已保存的歌词不会因解码器升级而被重新读取。如果这份记录已经乱码，先重新导入正确的 LRC 与音频，检查预览，确认新歌曲正常后再删除那首旧的乱码记录；新导入会有独立的学习进度，不会覆盖其他歌曲。
4. 更新后的文件夹歌曲使用基于文件名的稳定 ID，增删其他文件不会让记录串歌。旧版按排序生成的 ID，仅在旧缓存与整首歌词逐句内容及编号完全一致、且匹配唯一时自动迁移；无法确认归属的旧记录仍保留在本地备份数据中，但不会强行应用。文件改名会视为另一首歌曲，建议保持原文件名。
5. 注音缓存和手动读音修正按句子编号、原文及词素内容核对，不再只比较句数。内容或编号变化的行不再沿用旧修正和掌握状态；仍能核对一致的行保留。歌曲正文改变后，其旧 AI 复核及整句解析失效，可重新生成；仅修改时间戳不会清除读音修正。无法确认的乱码版本记录可能需要重新校对，但不会清空其他歌曲的数据。

内置歌曲和网页导入歌曲会尝试按歌名、歌手搜索封面；如需为内置歌曲指定封面，可在 `src/data/songArtwork.js` 中按 `sourceFile` 配置公开封面 URL 与来源页链接。专辑封面通常受版权保护。

## 本地完整日中词典（可选，但推荐）

项目不提交约 662 MB 的解压词典数据库。没有它时仍能自动注音，但可显示的中文释义会较少。

1. 从 [Tomoshi Dictionary Open Data Layer 的发布页](https://github.com/tomoshi-app/tomoshi-dict-data/releases) 下载 `tomoshi-dict-open.db.zst`。
2. 放到 `server/data/tomoshi-dict-open.db.zst`。
3. 在 `server/` 目录执行：

   ```powershell
   @'
   from pathlib import Path
   import zstandard as zstd

   source = Path('data/tomoshi-dict-open.db.zst')
   target = Path('data/tomoshi-dict-open.db')
   with source.open('rb') as reader, target.open('xb') as writer:
       zstd.ZstdDecompressor().copy_stream(reader, writer)
   '@ | .\.venv\Scripts\python.exe -
   ```

首次查询会使用该本地 SQLite 数据库；不会把歌词或查词内容发送给词典服务。公开部署、修改或重新分发词典数据时，请遵守 [THIRD_PARTY_DATA_NOTICES.md](../THIRD_PARTY_DATA_NOTICES.md) 中的署名与许可要求。

## 设置与 AI 服务

右上角 **设置** 提供“注音显示”“数据管理”和“AI 服务”。歌曲库中的“数据管理”也会打开同一面板。

### 平假名与罗马音

进入 **设置 → 注音显示**，选择 **平假名**（默认）或 **罗马音**，立即生效并自动保存在当前浏览器。歌词上方的注音、下方读音行、逐句练习答案、词语详情、AI 复核建议及 AI 返回的独立读音字段会跟随切换；日文歌词原文、词典形和解释正文不改写。“原文”和“遮住练习”模式仍然隐藏注音。

罗马音由本地 [WanaKana](https://github.com/WaniKani/WanaKana) 根据已有读音转换，不需要联网或调用 AI。例如 `ゆめ → yume`、`がっこう → gakkou`、`コーヒー → koohii`、`しんよう → shin'you`。长音保留为连续元音；根据词性识别出的助词「は／へ／を」显示为 `wa／e／o`，手动修正优先。它不会重新判断汉字读音，也不能表达所有歌唱细节；自动读音错误时仍需校对。

校对输入框继续使用假名，罗马音模式下附带实时转换预览；保存假名修正后，对应歌词注音和读音行的罗马音会立即跟随更新，无需重新导入歌曲。切换显示不会把原始注音或手动修正改存成罗马音。偏好会包含在学习备份中；旧备份没有这项设置时默认使用平假名。

### 网页配置 AI 服务

默认使用服务端已有的 DeepSeek 配置；服务端密钥不会返回浏览器。要使用自己的服务，取消勾选“使用服务端默认配置”，填写供应商名称、接口类型、API 地址、API Key 和模型名称。支持 DeepSeek，以及 OpenAI Chat Completions 兼容服务（包括提供此接口的本地模型）；暂不支持原生 Anthropic Messages 或仅提供 Responses 的接口。

- API 地址可填写基础地址（如 `https://api.openai.com/v1`）或完整的 `/chat/completions` 地址；模型 ID 按供应商说明填写。
- 远程地址使用 HTTPS；本机与局域网 IP 支持 HTTP。本地服务地址由 Python 后端访问。无需鉴权的服务可留空 Key；不会借用服务端 Key。
- 点击 **测试连接** 会发送一条短文本验证模型与 JSON 输出，可能产生少量调用费用；测试不会自动保存，请再点 **保存设置**。
- 不支持 `response_format` 参数的兼容服务可以关闭“JSON 输出模式”，但模型仍需返回合法 JSON。
- API Key 默认保存在当前标签页会话；勾选“在此浏览器记住 API Key”后才持久保存（明文）。密钥随 AI 请求发给网站后端转发，不写入服务端配置，也不进入学习备份。部署时应使用可信的后端连接。
- 更换 API 地址或快速预设会清空待填密钥，需为新服务重新填写；“清除配置”删除浏览器保存的配置与密钥并恢复服务端默认。
- 配置生效于后续读音复核、整句解析、片段讲解；已保存的解析仍然保留。不同浏览器的设置互不覆盖。

当前后端允许请求指定 AI 服务地址，面向本机和受信任的使用环境。不要直接将其作为无需登录的公共转发服务暴露到互联网；公开部署前需补充鉴权、出站目标限制及相应的额度控制。

接口参考：[DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[OpenAI Chat API](https://developers.openai.com/api/reference/resources/chat)。

### 可选：服务端默认 DeepSeek 配置

默认读音完全由本地 SudachiPy 生成。点击“确认导入并生成解析”“生成剩余解析”“生成解析”“AI 复核全曲”或片段的“AI 解释”时，才会向当前配置的 AI 服务发送必要的歌词上下文。没有配置 Key 时歌曲仍能导入，但整句解析暂时无法生成。

在 `server/` 下复制 `.env.example` 为 `.env`：

```powershell
Copy-Item server\.env.example server\.env
```

编辑 `server/.env`：

```ini
DEEPSEEK_API_KEY=你的 DeepSeek API Key
DEEPSEEK_MODEL=deepseek-flash
```

`.env` 已被 Git 忽略，绝不要把 API Key 写进前端代码、截图或公开仓库。

| 内容 | 保存位置 | 是否上传 |
| --- | --- | --- |

## 项目结构

```text
src/                   React 网页
  data/                自动生成歌曲数据、封面映射
  lib/                 注音 API、AI API、本地歌曲 IndexedDB
  assets/              原创主页背景图
server/                FastAPI、SudachiPy、可选本地词典
geci/                  内置 LRC 歌词
song/                  内置音频
scripts/sync-lyrics.mjs
```

注音服务对共享的 Sudachi 分词器加锁，避免多个请求并发使用时发生借用冲突。回归测试覆盖歌词编码、记录迁移、备份、浏览器 AI 配置、服务端供应商边界及并发注音；测试不会实际调用付费 AI 接口。
