# UTA Windows 1.1.28 使用说明

适用于 Windows 10 / 11 x64。解压发布 ZIP 的完整 `UTA-Windows-x64` 文件夹，双击其中的 `UTA.exe`。程序内置 Electron、Python 注音服务、Sudachi 与 Tomoshi 词典；无需安装 Node.js、Python 或 Java。第一次启动可能需要稍等词典加载。

## 歌曲导入与歌词检查

在歌曲库选择导入，可导入单首或批量选择音频与 LRC。批量导入优先配对本地同名歌词；本地没有歌词时，可选联网搜索 LRCLIB 或 UtaTen 的候选结果。选择结果后先检查歌曲版本、原文、译文和时间轴，再保存。联网歌词可能缺少时间轴，需要自行填写。歌词内已有的假名注音优先于自动注音。

导入预览把原文、译文、罗马音分轨显示；可改轨道、插入句子和修正异常时间戳。需要处理的歌词会在导入前提示。批量 AI 解析需用户明确勾选；不勾选时导入不会自动发送歌词给 AI。

导入、注音及 AI 解析的进度可在左侧任务面板查看。失败时显示原因，可重试或取消；已经保存的内容会保留。

## 发音学习与跟唱

发音学习页单击歌词选句，右键打开编辑菜单。可编辑该句原文、译文、读音、时间与自定义分词；修改分词后词下罗马音和假名会重新对应。词义与读音校对在右侧面板，拖动分隔条可调整宽度，设置会记住。

选中首句后按 Ctrl 点击末句，可连续选中中间所有句子；也可用 Shift+↑/↓ 扩展。选段从首句准确时间戳开始，至末句之后下一时间戳结束；单句播放仍使用原有提前量。选段支持 1×、0.75×、0.5×、0.25×，可播放 3 次、5 次或无限循环，设 1–3 秒跟读间隔，或选择“听一次→自己读→再听一次”。

左侧“跟唱练习”进入完整跟唱播放器。点击任一句可从该句开始连续播放；可切换假名＋罗马音、仅假名、仅罗马音或仅歌词，控制译文与歌词跟随。背景可选默认图片、本地图片或纯色，并调整模糊和遮罩。顶部标题栏与跟唱背景协调显示；底部播放器继续控制播放、进度、速度和音量。

设置 → 注音显示可分别调整歌词、上方假名、下方整句注音或词下罗马音，以及译文字号。设置 → 主题设置提供白羽翠风、星杖靛蓝、绯剑赤霞、旅途麦金四套主题。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 导入 / 搜索歌曲 / 设置 | Ctrl+O / Ctrl+F / Ctrl+, |
| 发音学习 / 歌曲库 / 复习 | Ctrl+1 / Ctrl+2 / Ctrl+3 |
| 导出学习备份 | Ctrl+Shift+E |
| 学习页上一句 / 下一句 | ↑ / ↓ |
| 学习页扩展连续选句 | Shift+↑ / Shift+↓ |
| 播放单句 / 播放或暂停 / 播放选段 | Enter / Space / Ctrl+Space |
| 编辑当前句 / 清除选段 | Ctrl+E / Esc |

在跟唱练习页，↑/↓ 选句，Enter 从当前句开始播放，Space 播放或暂停，Home 从头播放。快捷键在文本输入框中不会抢占输入。

## AI 与数据

设置 → AI 服务填写接口地址、模型与 API Key；先点“测试连接”，再点“保存设置”。Key 可以只在当前会话使用，也可以选择由 Windows 系统加密记住；不进入普通学习备份。AI 可按需生成整句解析，或复核读音和词典分词。复核建议可采纳、跳过或恢复。第三方 AI 的可用性取决于用户配置与服务状态，调用可能收费。

歌曲、音频、歌词、学习进度、缓存与日志都位于 `UTA.exe` 旁的 `uta-data`。在设置 → 数据管理导出或恢复 `.uta-backup`；恢复前会预览并自动保存快照，快照位于 `uta-data/backups/restore-snapshots`，通常保留最近三次。快照失败会停止恢复。编辑歌曲时可撤销与重做，关闭未保存编辑会提示；只改译文、时间或歌曲信息不会清除整首学习记录。

更新前退出 UTA，先备份 `uta-data`，再替换程序文件并保留原有 `uta-data`。发布 ZIP 不包含学习数据。跨电脑复制时一并复制 `uta-data`，但 Windows 加密的 API Key 要重新填写。当前版本仅在“帮助 → 查看 Windows 版更新”打开 Release 页面，不会自动安装更新。

## 故障与开发

启动失败可查看 `uta-data/logs/desktop.log`；文件缺失时重新解压完整发布包。联网歌词、封面和 AI 需要网络；本地注音、词典与已有歌曲学习可以离线使用。程序尚未购买代码签名证书，Windows 可能显示未知发布者。

源码分支为 `Windows-exe`。运行 `安装 Windows 开发环境.cmd` 安装项目本地依赖，再运行 `构建 Windows 程序.cmd`；或执行 `scripts/windows.ps1 setup`、`scripts/windows.ps1 test`、`scripts/windows.ps1 build`。打包生成便携目录、ZIP 和 SHA-256 文件，均在 `release/`。第三方授权见成品 `licenses` 与 `第三方数据说明.md`。
