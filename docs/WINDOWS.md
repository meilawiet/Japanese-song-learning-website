# UTA Windows 版

适用于 Windows 10 / 11 64 位。便携目录已包含 Electron、Python 注音服务、Sudachi 词典及 Tomoshi 日中词典，不需要另外安装 Node.js、Python、Java 或 Android 环境。

## 开始使用

双击 `release\UTA-Windows-x64\UTA.exe`。分享给其他电脑时复制整个 `UTA-Windows-x64` 文件夹，或将发布 ZIP 解压后运行 `UTA.exe`。程序必须放在当前用户可写的目录。

首启会加载本地词典。只会打开一个主窗口；再次双击会回到已有窗口。关闭最后一个窗口或选择“文件 → 退出”会关闭内置注音服务。

歌曲库可导入本地 MP3 与 LRC、编辑歌曲和歌词、替换封面。可自动生成逐词读音、平假名或罗马音显示，手动校正读音、查看中文词义、逐句练习、记录掌握进度和复习，以及使用选词解释、整句解析和读音复核。

本地注音、词义、歌曲播放和已有学习记录可以离线使用。AI、在线封面与歌词搜索需要联网。此版本采用固定侧栏、歌曲列表、歌词与校对双窗格及底部播放器的桌面工作区；Android 专用的手机发现、WebDAV 原生插件和 APK 更新流程不随 Windows 程序运行。

## 桌面操作

左侧切换发音学习、歌曲库与复习。歌曲列表单击可查看详情，双击开始学习；详情栏可编辑歌曲、换封面或删除本机导入的歌曲。使用“我的收藏”和排序选项整理歌曲。

学习区左侧显示歌词，右侧修改读音和查看词义；两个窗格独立滚动。点击歌曲标题栏的“逐句练习”进入练习，学习区不再显示重复的练习启动卡片。底部播放器可连续播放、跳到上一句或下一句、拖动进度、调节音量与倍速。没有音频时仍可学习歌词。切换页面不影响连续播放。

标题栏可以拖动窗口，右上角使用 Windows 原生窗口按钮。标题栏“文件、编辑、视图、帮助”打开原生菜单。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+O | 导入歌曲 |
| Ctrl+F | 打开歌曲库并搜索 |
| Ctrl+, | 设置 |
| Ctrl+Shift+E | 导出学习备份 |
| Ctrl+1 / Ctrl+2 / Ctrl+3 | 学习 / 歌曲库 / 复习 |

在“设置 → 注音显示”分别拖动“歌词上方假名字体大小”和“下方整句注音字体大小”滑块（均为 8–24 px）。两项独立控制，预览与歌词立即更新并自动保存，重启后保留。上方假名默认 10 px，下方整句默认 11 px，可分别恢复默认。歌词原文大小不变；切换罗马音后同样适用，学习备份会保留两个字号。

## 连续歌词片段播放

在学习页先点击首句，再按住 Ctrl 点击末句，中间句会一起高亮；也可反向选择。点击歌词文字、注音或句号旁的空白都可选择；按住 Ctrl 再点另一句可调整末端。正常点击单句或点击“取消歌词多选”清除片段选择。

歌词列表上方会显示所选句数与准确起止时间，点击“播放选中片段”即可播放；可暂停、继续或从头重播，慢放支持 0.75× / 0.5× / 0.25×。选段速度与底部播放器同步。

选段直接从首句时间戳开始，到末句之后的下一处时间戳停止；末句选到歌曲结尾时播放到音频结束。同时间戳的歌词使用下一处不同时间戳作为终点。此功能不提前 0.5 秒，原有逐句播放仍保留提前 0.5 秒的规则。

切换歌曲或修改歌词时间轴会清除所选片段。没有音频时可以选歌词，但播放按钮不可用。

## 批量导入

在导入窗口点击“批量导入”，分别选择多个音频与 LRC 文件。在 Windows 文件选择窗口中按 Ctrl 或 Shift 多选；也可再次点击选择区域继续添加。

同名文件自动配对，也会尝试唯一对应的歌名与歌手；重名或无法确认的文件保留为待配对，在每首音频旁的下拉框选择对应歌词。检查列表中的歌名、歌手、句数与状态后，勾选需要的歌曲，点击“导入选中的 N 首歌曲”。缺少歌词或解析失败的文件会显示原因，可先导入其他已配对的歌曲。

批量导入使用默认封面，成功后返回歌曲库；歌词、时间轴和封面可继续编辑，AI 解析可按需生成。文件读取和保存均在本机完成。若保存失败，不会留下部分导入记录，排除问题后可重试。

## 数据与 AI

所有程序数据、浏览器缓存、临时文件和日志都放在 `UTA.exe` 旁边的 `uta-data` 文件夹。菜单“文件 → 打开数据文件夹”可打开它。程序没有自动迁移原网页浏览器的资料；先在网页“设置 → 数据管理”导出 `.uta-backup`，再在 EXE 的相同入口导入。

备份保存时会弹出文件选择框，默认位置为 `uta-data\backups`。恢复会先展示预览，确认后替换当前学习数据。移动程序前关闭窗口，并连同 `uta-data` 一起复制。

AI 服务设置的“测试连接”和“保存设置”固定在窗口底部，填写区域可独立滚动。测试连接成功后仍需点击“保存设置”才能应用配置。

在“设置 → AI 服务”中取消“使用服务端默认配置”，选择供应商、填写地址、模型和 API Key，测试成功后保存。勾选“记住密钥”时使用 Windows 系统加密存储；不勾选时只保存于当前会话。API Key 不进入学习备份。系统加密的密钥跨 Windows 用户或电脑后需重新填写。

也可在 `uta-data\config.env` 中填写服务端环境配置，例如 `DEEPSEEK_API_KEY` 和 `DEEPSEEK_MODEL`。重启程序生效。该文件需要自行保管，不随软件发布。

## 项目开发

项目根目录是 `E:\project\UTA-exe`，Git 分支为 `Windows-exe`。

首次安装开发依赖：运行 `安装 Windows 开发环境.cmd`。构建：运行 `构建 Windows 程序.cmd`。二者将依赖与缓存保存在项目内。也可执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\windows.ps1 setup
npm.cmd run windows:package
npm.cmd run desktop:dev
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\windows.ps1 test
```

`desktop/` 是窗口、进程与协议实现；`src/` 是共享学习界面；`server/desktop_api.py` 是受本次会话密钥保护的本地服务；`desktop/backend.spec` 冻结 Python 与词典；`scripts/package-windows.mjs` 生成便携目录。打包会排除私人歌曲、歌词、API Key 和学习记录。

本地已有的 `server\data\tomoshi-dict-open.db` 用于打包词义功能。全新克隆请先按照项目安装脚本下载词典；缺失时打包会报错。开发用 Python 环境不是用户运行 EXE 的必要条件。

## 故障处理与更新

启动失败时查看 `uta-data\logs\desktop.log`。缺少文件时重新解压完整发布包。程序通过每次启动自动分配的本机端口提供注音，不占用原网页的 8000 / 5173 端口。

菜单“帮助 → 查看 Windows 版更新”打开项目 Release 页面，由用户自行下载 Windows 发布包。更新前退出程序，保留 `uta-data`；不要用 Android APK 更新 Windows 版。

发布程序尚未购买代码签名证书，Windows 可能显示未知发布者。是否允许运行由用户自行决定。第三方软件和词典的来源及授权见程序内 `licenses` 文件夹与“第三方数据说明.md”。
