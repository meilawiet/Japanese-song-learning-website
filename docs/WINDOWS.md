# UTA Windows 1.2.0 使用说明

适用于 Windows 10 / 11 x64。解压发布 ZIP 的完整 `UTA-Windows-x64` 文件夹，双击其中的 `UTA.exe`。程序内置 Electron、Python 注音服务、Sudachi 与 Tomoshi 词典；无需安装 Node.js、Python 或 Java。第一次启动可能需要稍等词典加载。

## 歌曲导入与歌词检查

在歌曲库选择导入，可导入单首或批量选择音频与 LRC。批量导入优先配对本地同名歌词；本地没有歌词时，可搜索已启用的在线来源。选择结果后先检查歌曲版本、原文、译文和时间轴，再保存。UtaTen 等来源可能缺少时间轴，需要自行填写。歌词内已有的假名注音优先于自动注音。

设置 → 歌词源可管理 LRCLIB、UtaTen、QQ、网易云、酷狗、酷我和 LRCLIB 兼容自定义接口。可快捷添加平台，或填写已适配平台的网址自动识别，保存后可测试搜索。已存在的 QQ、网易云、酷狗、酷我主页配置会自动使用对应专用接口，无需删除重加。选“全部已启用来源”时，某个来源失败不会丢弃其他来源的结果；限流等待期间不会反复请求该来源。平台没有提供的翻译或罗马音不会自动补造。

导入预览把原文、译文、罗马音分轨显示；可改轨道、插入句子和修正异常时间戳。英文／罗马音的自动归类不再要求逐行确认；其他需处理的问题会在导入前提示。批量 AI 解析需用户明确勾选；不勾选时导入不会自动发送歌词给 AI。

导入、注音及 AI 解析的进度可在左侧任务面板查看。失败时显示原因，可重试或取消；已经保存的内容会保留。

## 发音学习与跟唱

发音学习页单击歌词选句、双击播放单句，右键打开编辑菜单。可编辑该句原文、译文、读音、时间与自定义分词；修改分词后词下罗马音和假名会重新对应。词义与读音校对在右侧面板，拖动分隔条可调整宽度，设置会记住。三种注音及仅歌词使用统一的显示模式下拉框；学习页不再显示底部整曲播放器和逐句播放图标。

选中首句后按 Ctrl 点击末句，可连续选中中间所有句子；也可用 Shift+↑/↓ 扩展。选段从首句准确时间戳开始，至末句之后下一时间戳结束；单句播放仍使用原有提前量。选段支持 1×、0.75×、0.5×、0.25×，可播放 3 次、5 次或无限循环，设 1–3 秒跟读间隔，或选择“听一次→自己读→再听一次”。

左侧“跟唱练习”进入完整跟唱播放器。点击任一句可从该句开始连续播放；可切换假名＋罗马音、仅假名、仅罗马音或仅歌词，控制译文与歌词跟随。背景可选默认图片、本地图片或纯色，并调整模糊和遮罩。顶部标题栏与跟唱背景协调显示；底部播放器继续控制播放、进度、速度和音量。

发音学习与跟唱的假名＋罗马音、仅假名、仅罗马音均按分词对齐，假名位于词上方、罗马音位于词下方。设置 → 注音显示可分别调整歌词、假名、词下罗马音和译文字号。设置 → 主题设置提供白羽翠风、星杖靛蓝、绯剑赤霞、旅途麦金四套主题，歌曲、歌词和分词编辑弹窗也随主题切换。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 导入 / 搜索歌曲 / 设置 | Ctrl+O / Ctrl+F / Ctrl+, |
| 发音学习 / 歌曲库 / 复习 | Ctrl+1 / Ctrl+2 / Ctrl+3 |
| 导出学习备份 | Ctrl+Shift+E |
| 学习页上一句 / 下一句 | ↑ / ↓ |
| 学习页扩展连续选句 | Shift+↑ / Shift+↓ |
| 播放单句 / 播放或暂停 / 播放选段 | Enter / Space / Ctrl+Space |
| 编辑当前句 / 清除选段 | Ctrl+E / Esc |

在跟唱练习页，↑/↓ 选句，Enter 从当前句开始播放，Space 播放或暂停，Home 从头播放。快捷键在文本输入框中不会抢占输入。

## AI 与数据

设置 → AI 服务填写接口地址、模型与 API Key；先点“测试连接”，再点“保存设置”。Key 可以只在当前会话使用，也可以选择由 Windows 系统加密记住；不进入普通学习备份。AI 可按需生成整句解析，或复核读音和词典分词。复核建议可采纳、跳过或恢复。第三方 AI 的可用性取决于用户配置与服务状态，调用可能收费。

歌曲、音频、歌词、学习进度、缓存与日志都位于 `UTA.exe` 旁的 `uta-data`。在设置 → 数据管理导出或恢复 `.uta-backup`；恢复前会预览并自动保存快照，快照位于 `uta-data/backups/restore-snapshots`，通常保留最近三次。快照失败会停止恢复。编辑歌曲时可撤销与重做，关闭未保存编辑会提示；只改译文、时间或歌曲信息不会清除整首学习记录。

设置 → 检查更新提供“在线检查”和“本地增量包”两种方式。在线检查读取官方 Windows Release，优先下载适配当前版本的增量包；缺少匹配增量包或程序文件不匹配时，在发布了校验文件的前提下改用完整 ZIP。

本地方式可选择 `.utapatch`，或从资源管理器直接拖入 UTA 主界面，程序会打开更新页并离线校验。无需解压；若同目录存在同名 `.utapatch.sha256`，也会核对该文件。版本不匹配、包损坏或运行环境不兼容时拒绝安装。校验完成后，点击“退出 UTA、安装并重新打开”，独立更新进程才会切换版本；未保存编辑会先提示，新版无法正常启动时保留旧版供恢复。

**1.2.0 是首次公开带更新器的版本，本次不提供增量包。** 从 1.1.28 或更早版本升级，请退出旧版并备份 `uta-data`，把完整 ZIP 解压到新目录，再将旧 `uta-data` 复制到新版 `UTA.exe` 同级。发布 ZIP 不包含学习数据；后续版本的更新缓存位于 `uta-data/updates`。跨电脑复制时一并复制 `uta-data`，但 Windows 加密的 API Key 要重新填写。

## 故障与开发

启动失败可查看 `uta-data/logs/desktop.log`；文件缺失时重新解压完整发布包。联网歌词、封面和 AI 需要网络；本地注音、词典与已有歌曲学习可以离线使用。程序尚未购买代码签名证书，Windows 可能显示未知发布者。

源码分支为 `Windows-exe`。运行 `安装 Windows 开发环境.cmd` 安装项目本地依赖，再运行 `构建 Windows 程序.cmd`；或执行 `scripts/windows.ps1 setup`、`scripts/windows.ps1 test`、`scripts/windows.ps1 build`。普通打包生成便携目录、完整 ZIP 和 SHA-256 文件；`npm run windows:release` 还会读取上一次 Windows Release，在具备兼容版本清单时生成增量包及其 SHA-256 文件。1.2.0 只发布完整 ZIP；后续发布保留完整包并提供兼容增量包。第三方授权见成品 `licenses`、版本内 `app/dist-desktop/licenses/qq-lyrics.txt` 与 `第三方数据说明.md`。
