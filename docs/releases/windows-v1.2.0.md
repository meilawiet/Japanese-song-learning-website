# UTA Windows 1.2.0 更新公告

本次更新相对上次发布的 Windows 1.1.28，重点完善更新方式、歌词来源和学习界面。

## 新增应用更新

- 设置中新增“检查更新”，支持在线检查、下载、校验，以及退出后安装并重新打开。
- 新增“本地增量包”模式：手动下载适配当前版本的 `.utapatch` 后，可直接拖入 UTA 主窗口，或在设置中选择文件，无需解压。
- 校验版本、运行环境和文件完整性；版本不符或文件损坏时拒绝安装。有未保存的修改时会先提示，更新保留歌曲、学习记录和 API 设置。

## 扩展歌词搜索与配置

- 新增歌词源设置，支持启用、停用、编辑、测试搜索和快捷添加平台。
- 接入安卓端已有的 QQ、网易云、酷狗、酷我专用歌词接口；已有平台网址自动识别，无需删除重加。保留 LRCLIB、UtaTen 和 LRCLIB 兼容自定义源。
- 原文、译文和来源罗马音按时间轴保留；QQ 歌词支持专用解码，平台缺失的辅助轨不会伪造。
- 单个来源失败不影响其他搜索结果；增加重复请求合并、短期缓存和限流等待，改善错误提示。

## 统一阅读与播放体验

- 发音学习的三种注音模式以跟唱排版为基准，按分词对齐：假名在词上方、罗马音在词下方，字体和词间距统一。
- 调整跟唱歌词可用宽度和换行，减少长句末尾单字另起一行。
- 发音学习改用统一的显示模式下拉框，支持双击歌词播放单句；移除重复选项、单句播放图标和学习页底部播放器。
- 歌曲、歌词和自定义分词编辑弹窗跟随主题色；歌曲库及快速打开不再显示练习 Demo。
- 导入英文／罗马音歌词时不再要求逐行确认归类。

## 下载与旧版升级

本次只提供 **`UTA-1.2.0-Windows-x64.zip`** 和可选的 `.zip.sha256` 校验文件，**不提供增量包**。此前公开版本没有增量更新器，首次升级请先退出旧版、备份 `UTA.exe` 旁的 `uta-data`，完整解压新版，再将旧 `uta-data` 复制到新版 `UTA.exe` 同级。

完整解压后双击 `UTA.exe` 即可启动，无需另装运行环境；请保留完整程序文件夹。1.2.0 内置的更新功能用于安装后续版本；在线歌词与 AI 服务仍取决于网络和服务状态。
