# UTA Windows 1.2.2 更新公告

本次汇总自 Windows 1.2.0 发布后的改进；1.2.1 为此前提供的本地增量测试版。

## 歌词导入、编辑与 AI

- 歌曲库的歌曲信息编辑窗口支持联网搜索、预览并替换歌词，复用导入时的歌词来源与搜索功能。
- 改善纯英语与罗马音判断，保留独立纯汉字、纯英语原文；同时间戳的原文、译文和罗马音建立对应关系。存在歧义时仍可在导入预览调整，旧歌曲不会自动重新解析。
- AI 复核、分词建议及句子解析按用户修改后的歌词顺序编号，返回结果绑定实际句子。请求期间编辑歌词、分词或读音后，失效结果不再覆盖当前内容。
- 调整句子顺序保留未改原文的学习记录、人工读音和注音，相关旧 AI 解析重新生成。
- 批量导入支持逐首选择和搜索封面，去掉残留的逐句归类确认要求。

## 阅读、字体与桌面操作

- “主题设置”集中管理配色、字体、注音方式及歌词／假名／罗马音／译文四项字号；字体切换即时生效并记住选择，思源宋体支持多个字重。
- 新增“常规设置”：关闭窗口时可选择最小化到系统托盘或直接退出，也可记住默认选择；托盘可恢复窗口或退出程序。
- 新增“关于”：项目地址、QQ 交流群 **1125131374**，以及“检查更新”。
- 快速打开显示封面，按最近进入学习或跟唱的歌曲排序；仅查看歌曲预览不改变顺序。
- 精简逐句读音顶部布局；AI 复核建议全部处理后隐藏完成提示，为歌词留出空间。
- 修复从跟唱返回学习后歌曲继续播放、后续歌词继续被选中的问题。

## 更新方式

- 同时提供 1.2.0 → 1.2.2、1.2.1 → 1.2.2 两个直接升级的增量包，保留完整 ZIP 和各包 SHA-256 校验文件。
- 在线更新比较 GitHub / Gitee 的 Windows 版本；优先同版 Gitee 下载候选，失败后回退 GitHub。支持 Gitee 完整 ZIP 分片合并校验；无适配增量包或基线不符时改用完整包。
- Windows 更新只识别 `windows-v数字.数字.数字` 及对应 Windows 资产，忽略安卓 APK。

## 下载与旧版升级

- 首次使用：下载并完整解压 **`UTA-1.2.2-Windows-x64.zip`**，双击 `UTA.exe`。
- 当前为 1.2.0：选 **`UTA-1.2.0-to-1.2.2-Windows-x64.utapatch`**，无需先装 1.2.1。
- 当前为此前的 1.2.1 测试版：选 **`UTA-1.2.1-to-1.2.2-Windows-x64.utapatch`**。
- 增量包可拖入 UTA 主窗口；1.2.2 的设置入口为“关于 → 检查更新”。Gitee 受单附件大小限制，超限资产以分片提供，下载全部对应分片和合并工具后还原原文件，再解压 ZIP 或拖入 `.utapatch`。
- 1.1.28 及更早版本：退出旧版，备份 `uta-data`，将完整 ZIP 解压到新目录，再将旧 `uta-data` 复制到新版 `UTA.exe` 同级。

更新保留歌曲、音频、学习记录和设置；发布包不包含用户数据。请勿单独复制 `UTA.exe`。Windows 加密凭据跨电脑或用户后需要重新配置。第三方 AI 与在线歌词取决于网络和服务状态；本次未新增 Android 跨端同步。
