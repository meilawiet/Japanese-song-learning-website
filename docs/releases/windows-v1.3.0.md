# UTA Windows 1.3.0 更新公告

发布日期：2026-11-01。相对上次公开 Windows 1.2.2，本次更新集中完善单句练习、歌词纠错、桌面操作，并加入 WebDAV 跨端资料入口。

## 单句可以反复练，时间也能微调

在“慢放”右侧设置单句循环次数：1、2、3、5、10 次，自定义 1–99 次，或无限循环。总次数包含第一次播放；双击当前句可以暂停、继续，换句或退出当前播放会停止旧循环。

右键歌词 → 编辑歌词，可分别修改开始和结束时间，支持手动输入及 ±0.2 秒按钮。结束时间留空时，仍按下一句或音频结尾自动截断。单句播放保留原有的 0.5 秒提前量；Ctrl 选段继续从准确时间戳开始。只改时间不会清除已有注音与学习记录。

## 已经导入的歌词，也能重新分轨配对

如果英文被放进了罗马音，或译文对应错了句子，无需重新导入音频：进入“歌曲库 → 编辑歌曲信息 → 重新归类与配对”，把每行改为原文、译文、罗马音或忽略，并指定译文、罗马音对应的原文。

调整后先查看配对预览，再应用到草稿、保存修改；支持撤销和重做。原文未变且仍能对应的句子继续保留掌握、复习和读音校正，自带假名与手动结束时间也会保留。改变原文或句序后，过期的 AI 上下文会失效，后续复核以修改后的歌词为准。导入时已经丢弃的内容无法凭空恢复，需要从原歌词补回。

## 学习界面更顺手

- 双击歌词播放时不再自动选中词语；点具体词语才高亮并展开右侧词义栏。
- 点歌词空白处取消选词，并收起自动展开的右栏；手动打开的右栏会保持展开。
- 顶栏新增左右边栏开关，展开后保留此前调整的宽度。
- 重新打开程序时恢复上次正在学习的歌曲，保持暂停；原歌曲已删除时打开其他可用歌曲。

## 新增 WebDAV 跨端资料入口

“设置 → 跨端互通”可配置 HTTPS WebDAV、上传本机快照、下载并预览云端快照，再确认恢复。相同音频按大小和 SHA-256 校验去重复用；缺少的音频可按歌曲补下载。恢复前会建立本机恢复点，传输支持进度、取消和失败重试，中断后有恢复提示。

**当前恢复是整份替换，不是自动双向同步或学习记录合并。** 另一端需要支持相同的云容器 v3 / 歌曲目录 v2 协议。本次已用隔离的 Windows EXE 和本机模拟 WebDAV 验证，尚未完成真实公网 WebDAV 与兼容安卓 APK 的真机往返验收。

云快照默认不含 API Key；主动选择包含时需要再次确认。恢复时可保留本机 AI 配置，也可选择使用快照配置。主题、字体、字号和窗口偏好保留在 Windows 本机。WebDAV 密码由 Windows 加密保存；云快照内容本身没有额外加密，请自行管理云目录访问权限。

## 下载与升级

本次提供完整便携 ZIP，以及从下列版本直接升级到 1.3.0 的增量包，均附 SHA-256 校验文件：

| 当前版本 | 对应增量包 |
| --- | --- |
| 1.2.0 | `UTA-1.2.0-to-1.3.0-Windows-x64.utapatch` |
| 1.2.1（此前的本地测试版） | `UTA-1.2.1-to-1.3.0-Windows-x64.utapatch` |
| 1.2.2 | `UTA-1.2.2-to-1.3.0-Windows-x64.utapatch` |

在“设置 → 关于 → 检查更新”在线下载安装，或将匹配当前版本的 `.utapatch` 拖入程序，确认“退出 UTA、安装并重新打开”。无需依次安装中间版本，更新保留 `uta-data`。1.2.1 包对应此前实际提供的测试构建；文件与基线不一致时请改用完整 ZIP。

从 1.1.x 或更早版本升级，请退出旧版并备份 `uta-data`，完整解压新 ZIP，再把旧 `uta-data` 复制到新版 `UTA.exe` 同级。此前使用过同版本号 1.3.0 的本地测试构建，也请用正式完整 ZIP 手动迁移；同版本号不会提示在线升级。不要直接用测试增量替代本次正式包。

新版本继续读取旧本地学习备份。含纯歌词、待下载音频或空时间的新本地备份需要用新版恢复；仅含音频引用的云快照不等于完整离线备份。
