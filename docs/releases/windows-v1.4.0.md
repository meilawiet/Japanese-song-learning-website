# UTA Windows 1.4.0 更新公告

相较于 1.3.0，这次更新集中在歌词编辑、AI 复核和 Windows 操作。

- **听歌与练习**：发音学习页「键盘操作」右侧新增音量按钮，与跟唱播放器共用音量。跟唱译文跟随歌词字体，译文字号仍可单独调整。窄窗下长歌名优先显示两行，必要时可打开完整名称。左右栏空间不足时，校对栏会转为抽屉，保留正在编辑的读音。
- **编辑后回到原位**：歌曲库保留搜索、收藏筛选、排序、选中歌曲和滚动位置。歌词重排后继续定位同一句，删除当前句时移到相邻句，返回时保持暂停。
- **整首歌词编辑**：未配对和冲突的歌词可按类型查看并定位。在整首编辑内可以打开指定句的分词与读音，也能更换封面。改动进入同一份草稿，可撤销、重做，再一起保存。
- **AI 复核与设置**：整首复核可从任务面板发起，支持查看进度、取消和重试，完成后可从待处理建议进入校对。离开尚未保存的 AI、歌词源或 WebDAV 配置时，程序会提示保存、放弃或继续编辑。
- **数据与帮助**：「设置 → 数据管理」集中提供本地备份和 WebDAV 跨端互通。「设置 → 帮助」新增 Windows 操作指南，覆盖导入、学习、跟唱、AI 配置和常用快捷键。

## 下载和升级

- **首次安装**：下载完整 ZIP，解压后双击 UTA.exe。从 Gitee 下载时，将完整 ZIP 的全部分片和合并工具放在一起，运行工具合并并校验。[GitHub 发布页](https://github.com/meilawiet/Japanese-song-learning-website/releases/tag/windows-v1.4.0) · [Gitee 发布页](https://gitee.com/mzh18392597195/uta-windows/releases/tag/windows-v1.4.0)
- **从正式 1.3.0 升级**：在「设置 → 关于 → 检查更新」下载，或将 1.3.0 → 1.4.0 的 .utapatch 拖进 UTA 主窗口。确认安装后，程序会退出更新并重新打开，歌曲和学习记录保存在原目录。
- **其他版本**：请使用完整包升级。支持在线更新的旧版可在设置中检查更新。手动迁移时，退出旧版并备份 uta-data，将它复制到新版 UTA.exe 同级目录，再启动并核对资料。

完整包和增量包均附 SHA-256 校验文件。
