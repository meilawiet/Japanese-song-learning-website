## 1.1.5 连续歌词片段播放

- 学习页新增 Ctrl 连续范围选择；可点击整句、注音或词语选择末端，首末之间全部高亮，反向选择同样适用，正常点击词语或取消按钮清除范围。
- 选段控制提供准确起止时间、播放、暂停、继续、从头重播及慢放；与底部播放器速度和暂停状态同步。
- 使用 6 秒原创测试音频和 0.5 / 1 / 2 / 4 秒歌词时间戳，实际点击第 2–3 句时从 1 秒开始并停在 4 秒，未使用 0.5 秒提前量。
- 实测 0.5× 播放、暂停后从同一位置继续、播放中切换 0.25×、靠近选段终点时自动停止、从选段起点重播；第 3–4 句从 2 秒开始并停在音频末尾 6 秒。
- 原单句第 1 句时间戳 0.5 秒，仍从 0 秒开始，原有提前 0.5 秒规则保持有效。
- 重复时间戳采用下一处不同时间戳；稀疏 ID、短于 0.12 秒的片段、无效时间戳和音频长度边界经检查；切换歌曲和歌词变化时清除范围与停止计时。

## 边界

Windows 10 尚未单独在另一台机器上运行；这是面向 Windows 10 / 11 x64 的构建，并在当前 Windows 11 上实测。第三方 AI、在线封面、在线歌词的真实外部服务质量与可用性取决于网络和用户配置；它们不影响离线注音、词义与已有歌曲学习。

该版使用独立桌面工作区与学习备份流程，Android 原生 WebDAV、手机发现和 APK 更新未启用。保留本地数据后更新整个程序目录；Windows 系统加密密钥跨用户或电脑后需要重新填写。

详细自动检查由 `npm.cmd run test:desktop` 执行，截图和 JSON 证据保存在本机项目 `work/verification` 中；整理后保留副本于 `verification`。
