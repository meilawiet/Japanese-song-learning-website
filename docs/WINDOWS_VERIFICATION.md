验证日期：2026-10-16。版本：1.2.0。目标：Windows 10 / 11 x64；本机实际运行环境：Windows 11 x64。

## 1.2.0 本次发布核验

- 相对上次公开 Windows 1.1.28 核对全部累计变更；README、使用说明和更新公告已按 1.2.0 更新。本次仅发布完整 ZIP 和 SHA-256 校验文件，不发布增量包。
- 145 项 Node 测试、14 项 Python 测试和生产构建通过。完整打包 EXE 的 50 项界面／集成检查通过，覆盖本地导入、词典、模拟 AI、主题编辑窗口、分词注音、双击播放、选段循环、备份恢复及重启后数据持久化。
- 额外打包 EXE 检查通过：联网歌词导入 6 项、歌词源配置 10 项、平台接口和歌词轨道 8 项、本地增量更新 8 项。联网导入的界面回归使用模拟服务；此前本机 Windows 平台接口实测已返回 QQ、网易云、酷狗、酷我的候选和歌词，第三方服务仍可能受网络、限流和平台变更影响。
- 本地更新在隔离副本中模拟 1.2.0 → 1.2.1：错误版本和损坏包被拒绝；拖入包、未保存编辑拦截、独立更新程序安装、重启健康确认及歌曲、音频、进度、收藏和 Windows 加密凭据保留均通过。模拟版本不用于本次发布。
- Windows 在线更新只识别 `windows-v数字.数字.数字` 标签并要求对应 Windows x64 ZIP；安卓标签及 APK 不会被当作 Windows 更新。增量包还必须匹配当前起始版本。
- 正式目录更新前完整快照并逐文件核对 `uta-data`；发布 ZIP 排除整个用户数据目录和其他旧版本程序目录。
- 实际运行环境为 Windows 11 x64；Windows 10 未在另一台机器单独验收。真实付费 AI 未作为本次测试，模拟 AI 通过不代表外部服务持续可用。

## 1.1.8 学习记录保护、编辑撤销与恢复前快照

- 76 项 Node 自动检查通过，38 项完整 EXE 成品检查通过（包含原有 29 项和本次 9 项）。使用独立便携测试目录、原创 WAV/LRC 和模拟 AI，不读取用户歌曲或真实密钥。

- 快照分块写入、落盘后发布；仅轮换本程序生成的快照，通常保留 3 次。异常临时文件不当作可恢复文件；无关手动备份不删除。
- 1000×680、125% 缩放下检查编辑内容可滚动、保存按钮及表单边界可见，并使用 Electron 原生截图复核（避免 CDP 在 DPI/缩放下的裁切偏差）。
- 本地便携目录更新后 290 个用户数据文件 SHA-256 汇总与更新前一致。GitHub 未同步；ZIP 排除整个 uta-data。

## 边界

Windows 10 尚未单独在另一台机器上运行；这是面向 Windows 10 / 11 x64 的构建，并在当前 Windows 11 上实测。第三方 AI、在线封面、在线歌词的真实外部服务质量与可用性取决于网络和用户配置；它们不影响离线注音、词义与已有歌曲学习。

该版使用独立桌面工作区与学习备份流程，Android 原生 WebDAV、手机发现和 APK 更新未启用。保留本地数据后更新整个程序目录；Windows 系统加密密钥跨用户或电脑后需要重新填写。

详细自动检查由 `npm.cmd run test:desktop` 执行，截图和 JSON 证据保存在本机项目 `work/verification` 中；整理后保留副本于 `verification`。
