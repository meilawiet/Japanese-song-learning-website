## 边界

Windows 10 尚未单独在另一台机器上运行；这是面向 Windows 10 / 11 x64 的构建，并在当前 Windows 11 上实测。第三方 AI、在线封面、在线歌词的真实外部服务质量与可用性取决于网络和用户配置；它们不影响离线注音、词义与已有歌曲学习。

该版使用独立桌面工作区与学习备份流程，Android 原生 WebDAV、手机发现和 APK 更新未启用。保留本地数据后更新整个程序目录；Windows 系统加密密钥跨用户或电脑后需要重新填写。

详细自动检查由 `npm.cmd run test:desktop` 执行，截图和 JSON 证据保存在本机项目 `work/verification` 中；整理后保留副本于 `verification`。
